# Hard Truck Web

Порт гри *Hard Truck / Дальнобойщики* (SoftLab-NSK, 1998) у браузер. Основна платформа — **мобільні** (touch, ландшафт, PWA).
Мова спілкування та документації — **українська**.

## Ключові документи
- План і статус: `Docs/04-roadmap.md` (оновлювати чекбокси після кожної задачі)
- Формати файлів гри: `Docs/01-analysis.md`
- Архітектура: `Docs/03-architecture.md`

## Підхід
Реімплементація рушія (TypeScript + Vite + Three.js + Rapier), яка читає оригінальні ресурси.
Не емуляція `HTruck.exe`.

## Розташування
- `Game/Hard Truck/` — оригінальна гра. **Лише читати. Ніколи не змінювати, не комітити, не публікувати.**
- `re/` — проєкт Ghidra для `HTruck.exe` (не комітити); висновки в `re/notes/*.md`. План: `Docs/07-reverse-engineering.md`
- `tools/probe/` — Python-зонди форматів (`python -I tools/probe/probe_rmp.py <file>`)
- `web/` — веб-порт (створюється у Фазі 0)

## Правила
- Парсери форматів покриваються golden-тестами на реальних файлах (читати до останнього байта).
- Параметри (вантажівки, матеріали, події) — з файлів гри, не хардкод.
- Кожну UI/рендер-фічу перевіряти у мобільному вʼюпорті (preview + `resize_window mobile`).
- Ресурси гри не потрапляють у git (`Game/`, `build/assets/`, `*.zip`, `*.avi` — у `.gitignore`).
- Не копіювати дизасембльований код з `HTruck.exe` — лише власна реалізація поведінки.
