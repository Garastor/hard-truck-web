# Запуск вільної їзди чи кар'єри

Мета — 2–3 виклики: сервер → адреса → дочекатися готовності. Без читання коду — усе потрібне нижче.

## 1. Яка гра й режим
Не сказано, яка гра, — друга (HT2, нею зараз займаємося); не сказано режим — вільна їзда. Для кого вкладка:
- **Користувач гратиме сам** — без `&mute`, вкладку вивести наперед (`tabs_select`), після запуску не чіпати
  (памʼять «руки геть, коли гравець їде»).
- **Для перевірки** (Claude сам) — `&mute`, окрема вкладка, після — закрити (скіл `verify-in-game`).

## 2. Сервер
Сесія в git worktree чи бриф каже «свій порт 518x» — не цей розділ, а скіл `launch-own-port`.
`preview_start({ name: 'web' })` (порт 5173). Помилка «Port 5173 is already in use» — сервер іншої сесії з цієї ж
теки, **не зупиняти**: той самий код, просто `navigate` на адресу нижче (панель ще не відкрита — `navigate` її
відкриє; відкрита — `tabs_create`, потім `navigate` з `tabId`, щоб не чіпати вкладку користувача).

## 3. Адреса (`http://localhost:5173` + …)

| | Вільна їзда | Кар'єра |
|---|---|---|
| HT2 | `/ht2/?tab=drive&truck=ZilR` | `/ht2/?tab=career` |
| HT1 | `/ht1/?tab=drive&level=COUNT&truck=1&ai=3` | `/ht1/?tab=drive&career=1` |

- HT2: `truck` — `car_node` машини (`Zil`, `ZilR`, `Kamaz`…; без нього — з `GAME.CNF`), `&trailer=…`,
  `&weather=…`; `?tab=race` — гонка, `?tab=world&region=ab` — огляд світу. Кар'єра відкриває **найновіше
  збереження** (`ht2.save.<id>`), немає жодного — нову гру поточного водія.
- HT1: `level` — `COUNT|MOUNT|NIGHT|CIRCUIT|TRIAL|MENU3D`, `truck` — 1…9, `ai` — суперники 0…7; погода тесту —
  з `ht.testWeather` (чи `ht.dev.setup({ weather })`). Кар'єра продовжує збереження `ht.careers.v1`.
- **Кар'єра для перевірки** пише в те саме збереження, що й у користувача (одне походження — одне localStorage).
  Перевіряти на окремому сервері `web-alt` (порт 5174 — окреме сховище) або скопіювати ключ збереження перед
  тестом і повернути після (памʼять про спільне збереження кар'єри).

## 4. Дочекатися готовності
`javascript_tool` (перший запуск читає ресурси — до хвилини):

```js
// HT2
for (let i = 0; i < 120 && !window.ht2?.drive; i++) await new Promise(r => setTimeout(r, 500));
const d = window.ht2?.drive;
d ? { ready: true, truck: d.def?.carNode, career: !!d.careerMode, ui: !!d.escArt } : 'не запустилось'
```

```js
// HT1
for (let i = 0; i < 100 && !window.ht?.dev; i++) await new Promise(r => setTimeout(r, 300));
await ht.dev.ready();
ht.dev.info()
```

Не запустилось — знімок (`computer screenshot`, `scale: 0.5`): головне меню замість їзди буває, якщо сторінка
ще вантажилась (повторити очікування), або бракує файлів гри (повідомлення на екрані «Файли гри»).

## 5. Користувачу
Одним рядком: яка гра й режим, машина, де вкладка. Керування HT2 з клавіатури (`engine/input/input.ts`): стрілки — кермо,
газ, гальмо; Shift — ручник; Esc — меню; C — камера; L — фари; Tab — карта; P — автопілот; R — на дорогу; F1–F5 —
панелі; телефон — ті самі адреси з ПК у мережі (`Docs/play-on-phone.md`).
