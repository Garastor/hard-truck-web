# Реверс king.exe і даних HT2

Висновки — у `re/notes/ht2/` (`ui.md` — інтерфейс, `physics.md` — фізика, `telemetry.md` — телеметрія), правила гри —
`Docs/ht2/gameplay.md`, план — `Docs/ht2/plan.md` (G9, G10). **Прочитати релевантне перед пошуком.**
Код **не копіювати** — лише поведінка словами й числами; «підтверджено (адреса)» чи «гіпотеза».
Інструменти — `tools/re/ht2/README.md`; Python — `.venv/Scripts/python -I`. Файли гри лише читати; вивантаження й
розшифровки — у scratchpad чи `exports/` (поза git).

## Джерела — від дешевого до дорогого
1. **Посібник** `king.chm` (25 розділів, 85 знімків): `manual.py "D:/Games/Hard Truck 2/king.chm" <тека>` →
   `manual.txt`. Найкраще джерело правил і вигляду (табло, рація, найм, сервіс).
2. **Тексти гри**: `mess.txt` (написи інтерфейсу, підказки, фрази рації; індекс — `mess.py`), `Ms.sch` (повідомлення
   й штрафи), `GAME.CNF` (`police 15`, `mafia 8`, `forhire 20`…), `mod_*.sch` (засідки `ambush`, СТО, ринки):
   `sch.py <тека> "<гра>/*.sch" "<гра>/ENV/*.sch" "<гра>/ENV/GAME.CNF"`.
3. **Графіка**: `COMMON/esc16.RES` (інтерфейс у дорозі), `LOAD.RES` (меню) → PNG:
   `EXPORT_RES=… EXPORT_OUT=… npx vitest run test/ht2/tools/exportRes.test.ts` (у `web/`). Аркуші для перегляду —
   PIL (`Read` показує PNG).
4. **Рядки** king.exe: `strings.py king.exe <out> "<регулярка>"` — імена картинок (`\.(msk|txr)`), звуків
   (`Sound$`), класів (`_Car_V`, `copter`), полів tech. Рядки однієї функції лежать у **зворотному** порядку.
5. **Декомпіляція** (повна, локально): `GQ_GAME=ht2 .venv/Scripts/python -I tools/re/gq.py exportall re/decomp_king`
   (≈ 10 хв, у фоні) → `grep` по `re/decomp_king/*.c`. Хто використовує рядок: `gq.py strings "<текст>"`;
   асемблер: `gq.py disasm 0x… N`. Не запускати `gq.py`, поки працює MCP `pyghidra-mcp` (проєкт блокується).
6. **Графіка ↔ код**: `uimap.py re/decomp_king <імена> <out>` — функція → картинки, кнопки й координати.

## Домовленості king.exe (перевірено)
- Набори картинок: `m16`/`m_16` — 16-біт, `m15`/`m_15` — 15-біт (вибір 0x568fd0() == 2); у порту — лише 16.
- Стани кнопок: `_p` — звичайна, `_a` — під курсором, `_ap` — натиснута, `_pp` — вибрана, `_f` — недоступна;
  прапорці `check_*`: `_n` — недоступно, `_ok` — уже є/справно.
- Конструктори віджетів: 0x50def0 — кнопка, 0x50d1c0/0x50d530 — прапорець, 0x50d860 — повзунок; позиція — поля
  +0x2c (x), +0x30 (y) віджета, відносно фону вікна.
- Текст (0x5ea170): (x, y) — **базова лінія**; шрифти `menu.fon` (вікна), `matrix.fon`/`icon.fon` (табло; значки
  табло — символи `icon.fon`, цифри дрібні = код + 0x10).
- Бічні панелі (фон 1200 заввишки): видно середину — рядок 650 посередині екрана (для 640×480 y = −410);
  праві — вікна біля обʼєктів, ліві — Esc і F1–F4. Табло — `tablo.txr` 1600×50, дані з x = 469.
- Повідомлення-картки: `eventBanner(N)` → `m16\mess<N>.msk` праворуч, y = 50.
- Аргументи x87 і push через регістр Ghidra часто губить (`FUN_005ef3d0()` без імені) — дивитись `disasm`.
