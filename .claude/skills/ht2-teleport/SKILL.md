# Телепорт у HT2

Робити **у вкладці користувача** (він просить перенести саме себе), без перезавантаження. Без читання коду — усе
потрібне нижче. Ціль — 1–2 виклики `javascript_tool`.

## 1. Знайти точку
Знайти вкладку (`tabs_context`, вкладка «Дальнобойщики 2») і одразу виконати (повторює чекання, бо Vite може
щойно перезавантажити сторінку після правок інших сесій, і `window.ht2` зʼявляється лише після завантаження):

```js
for (let i = 0; i < 20 && !window.ht2?.drive; i++) await new Promise(r => setTimeout(r, 1000));
const d = window.ht2.drive;
// Пункти карти: town (з підписом міста), fuel, market (P, з назвою), sto (ремонт).
d.tabMap.points.map(p => [p.kind, p.label, Math.round(p.pos.x), Math.round(p.pos.z)])
```

Координати карти = світові `x`, `z` (північ карти — `−z`, схід — `+x`). Перетворення карти-огляду
(`ui/tabMap.ts`, `draw`): `екран = (ox + x·k, oy + z·k)` у CSS px, де
`k = min((innerWidth − 80)/size.x, (innerHeight − tablo − 130)/size.y)`, `ox = 40 − bounds.min.x·k`,
`oy = tablo + 40 − bounds.min.y·k` (`tablo = d.tabMap.top`, `bounds/size` — `d.tabMap.bounds`). Мінікарта
(режим 2) центрована на машині з масштабом `2k`.

**Знімок карти з колом.** Розпізнати на знімку підпис міста та сусідні значки (P — `market`, бензоколонка —
`fuel`, білий будиночок — `town`, гайковий ключ — `sto`), знайти їхні світові координати в списку вище й
відкласти зсув кола від найближчого значка. Масштаб знімка відомий лише приблизно, тож орієнтир — близько
**16 одиниць світу на піксель** знімка огляду; похибка ~100 м нормальна. Приклад (перевірено): коло над
верхньою P (ринок Moal, −2538, −575) біля ПРИОЗЕРСЬКА → точка ≈ (−2505, −870).

## 2. Поставити машину
Користувач майже завжди хоче **на дорогу** — ставити на найближчу точку доріг карти з напрямком уздовж неї
(`TX`, `TZ` — ціль):

```js
const d = window.ht2.drive, TX = -2505, TZ = -870;
let best = null;
for (const l of d.tabMap.lines) for (let i = 0; i + 1 < l.pts.length; i++) {
  const a = l.pts[i], b = l.pts[i + 1], dd = Math.hypot(a.x - TX, a.z - TZ);
  if (Math.hypot(b.x - a.x, b.z - a.z) > 0.5 && (!best || dd < best.dd)) best = { dd, a, b };
}
const V = d.truck.visual.position.constructor;
const f = new V(best.b.x - best.a.x, 0, best.b.z - best.a.z).normalize();
const p = d.groundAtPublic(new V(best.a.x, (best.a.y ?? 20) + 5, best.a.z));
d.truck.reset({ position: p, forward: f });
d.trailer?.reset();
d.skipHits = 3;
({ p: [p.x, p.y, p.z].map(Math.round), dd: Math.round(best.dd) })
```

Не на дорогу (точно в місце) — замість пошуку `best`:
`d.truck.reset({ position: d.groundAtPublic(new V(TX, 60, TZ)), forward: new V(0, 0, -1) })`.

## 3. Перевірити
Один знімок (`computer screenshot`, `scale 0.5`): машина на дорозі, на мінікарті позначка біля потрібного місця.

## Пастки
- Далеко від старту регіони цілі ще не завантажені (колізій немає — машина падає чи стає на чужий схил): після першого
  `reset` чекати, доки `d.colliders` має регіони місця і `d.wallsPending` порожній (до 20 с), повторюючи `reset`,
  і лише тоді ставити остаточно. Регіон — дві літери кімнати (`aw` для room_aw_001); `d.roomBounds.roomOf(d.truck.body)`.
- Напрямок уздовж осі може дивитися в узбіччя на вигині — перевіряти знімком; відома точка «невидимої стіни» біля
  Приозерська: (−2482, 22, −1584), курс (0,87, 0, −0,49), регіони aw + av.
- **Ціль задавати числами, не від поточної позиції машини**: якщо сторінка між викликами перезавантажилась,
  машина знову на старті й «найближча дорога» виявиться стартовою.
- `window.ht2` зникає на кілька секунд після перезавантаження — чекати циклом (п. 1), а не повідомляти про помилку.
- `groundAtPublic` бере висоту з колізій: висока стартова `y` над будівлею поставить машину на дах — для «точно
  в місце» перевіряти `p.y` (дороги — близько 20–30).
