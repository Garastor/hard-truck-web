# HT2: звуки ходової машини (2026-10-24)

[К] — код king.exe (адреса), [Д] — дані гри, [Г] — гіпотеза. Код не копійовано. `veh` — обʼєкт машини
(`param_1+0x268` у 0x538370), `ph` = [veh+0x5460] — фізика Car_V.

Гравцеві звуки — 0x538370 (щокадру, там же сигнал, двигун 12–15: машини < 3000 кг — `jidle`/`jfull`). Кожен звук:

## Двигун — петлі 12–15 [К 0x538dc2…0x5390f8]
Стан двигуна [veh+0x5214]: 2 — працює, 3 — глушіння. Значення машини — копія стану 0x54d690 ([veh+0x27b4…] →
[veh+0x51e0…], те саме, що телеметрія з +0x90): [veh+0x51e8] = n (оберти, об/с; телеметрія +0x98),
[veh+0x51f0] = n₀ (tech +0x10c, `tach_with_max_power`, за замовчуванням 20; 0x5427a0), [veh+0x51f8] = педаль газу g
(+0xa8). r = n / n₀, s = min(1, g + r), V = 1 (працює):
- **idle** (12, або **jidle** 14, якщо маса [veh+0xcd4] ≤ 3000 — 0x64f3f8): гучність s·min(1; 0,1·√r·V) +
  (1 − s)·(0,4g + 0,2)·V, тон s·(0,8r + 0,2) + (1 − s)·(0,2r + 0,8).
- **full** (13 / **jfull** 15): гучність 0,5·√s·(0,3g + 0,7)·V, тон 0,8·√s·r + 0,2.
- Константи (double): 0x64b840 0,2, 0x64b898 0,8, 0x64ca78 0,4, 0x64b5b8 0,1, 0x64d0f0 0,3, 0x64b7a8 0,7, 0x64b6e0 0,5.
- Грає 0x52f7b0 (у кабіні, 2D) / 0x52f830 (зовні, 3D, радіус 10): гучність → 0x52f760 × налаштування [0x6cec78+0x184]
  → 0x5fd430 (обмеження 0…1, × 0,99 — лінійна, в дБ переводить бібліотека); тон → 0x5fd5c0: × 1000 → канал
  ([Г] проміле рідної частоти: записи 11025 і 44100 Гц, тон 1 біля n₀).
- **Глушіння (стан 3)**: лічильник кадрів [0x6d1db0] (byte) × dt / 2,98 (0x67440c — тривалість stop_eng.wav) = t;
  **stop_eng** (слот 10) гучність 0,4, а поки t < 0,5 — 0,8·t; петлі двигуна — лише поки t < 0,5, з V = 2·(0,5 − t).
- Порт: `engine/audio/engineMix.ts` (Docs/ht2/vehicle.md «Звук двигуна»).

## «Пшш» пневмогальм [К 0x538370, кінець]
- Лише машини з масою [veh+0xcd4] **> 5000** кг (0x64f3e0).
- Стан «гальма» = педаль [ph+0x3bd0] (копія [ph+0x29dc]) **> 0,1** **або ручник** [ph+0x3c50] (0x500850: перемикач
  [ph+0x2718] ≥ 2 → 1).
- Стан змінився: 0 → 1 (взялись) — **`pss2`**, 1 → 0 (відпустили) — **`pss`**; гучність 1.
- Стан 0 і швидкість [ph+0x3328] (= |v|, [ph+0xdc0], 0x4ef7c0) < **0,1** м/с: якщо з минулого такого кадру минуло
  **> 1 с** (0x678780) — ще **`pss2`**; час [0x6d20d8] оновлюється щокадру, поки умова діє (тобто раз на зупинку).

## Вереск шин — петля `break` [К 0x54a380 → 0x54d690 → 0x538370]
0x54a380 (щокадру машини) рахує гучність у [veh+0x522c] (через [veh+0x28ac]) і тон у [veh+0x5228]; на вході кадру —
0. n — кількість коліс (таблиця 0x6980c8 за типом [ph+0x8cc]). Для кожного колеса i:
- **A_i** = [ph+0x3444+4i] = 0 і [ph+0x346c+4i] ≠ 0 і контакт ([ph+0x2b68+0xf8i] ≠ 0) і [[ph+0x2bd4+0xf8i]] = 1;
  **B_i** — те саме з [ph+0x348c+4i]. [Г: A — колесо ковзає вбік, B — буксує чи заблоковане — як прапорці слідів
  [0x19c4], [0x19d4] у wheel-effects.md.]
- Далі лише якщо (є A і [ph+0x332c] (горизонтальна швидкість) > 0,5) або є B.
- s_i = min(1, |[ph+0x338c+4i]| / 0,349) [Г: кут ковзання колеса, 20°]; S = 0,3·Σ A_i·s_i.
- f(u) з [ph+0x3330] (швидкість уперед; 0x54a330): u < 5 → 0,3; u > 20 → 1; інакше (u − 5)·0,04667 + 0,3.
- **V = S·f + S + 3·(0,06·A₀·A₁ + 0,3·A₂ + 0,2·A₃) + 0,15·(B₀ + B₁ + B₂ + B₃)**.
- Покриття ([[contact]+4]) коліс з A: 1, 5 → +1, 2, 6 → −1; Σ = 0 і ΣB = 0 → звуку немає. Тон 0,7, якщо Σ < 0,
  інакше 1. **Гучність = min(1; 0,3·V)**.
- 0x538370: гучність ≠ 0 → 0x52f910(`break`, гучність) → 0x52f8b0: × налаштування [0x6cec78+0x186] (повзунок
  «звук торможения», INI `skivol`), петля оновлюється щокадру (0x5fd430), без оновлення замовкає. **Тон не
  передається** (третій аргумент 0x52f910 ігнорується).

## Удари — масив 0x6d1d54 [К 0x54d0b0 → 0x538370]
11 подій [veh+0x5468+4i] з точкою [veh+0x5494+0xc·i] і гучністю [veh+0x5518+4i]: 0–2 `hit_gluh_f/m/r` (подія 0 —
випадково f/m/r), 3 `hit_gluh_squeak`, 4 `hit_def1`, 5 `hit_def2`, 6 `hit_def_fara`, **7 `hit_suspension`**,
8 `hit_sign`, 9 `hit_ironpillar`, 10 `hit_bullet`. Грає 0x52f9d0 (× налаштування [0x6cec78+0x182]) у точці.
- **Подія 7** (0x54d0b0, коли [ph+0x3344] = 0): є колесо з [ph+0x3be8+4i] > 0 — сила пробою підвіски (physics.md:

  машини [veh+0x228]. Тобто звук — лише коли підвіска пробивається (приземлення після трампліна, яма).

## Порт
`drive.vehicleSounds` (щокадру після звуку двигуна): `pss`/`pss2` за `TruckVehicle.airBrakeOn()` і `totalMass`;
петля `break` — `TruckVehicle.skidLevel()` (A = `skid`, B = `slip`, α = `skidAlpha`) × повзунок «заноси» на
покриттях 1, 2, 5, 6; `hit_suspension` — `TruckVehicle.suspHit` (Σ сил відбійників / масу за кроки кадру) / 10,
без накладання. Звуки 2D (без 3D-положення й радіуса). Журнал — `window.ht2.drive.vehicleSoundLog`.
