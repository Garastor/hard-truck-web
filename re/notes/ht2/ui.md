# HT2: графіка інтерфейсу в дорозі — що, де й коли малює king.exe

Висновки з реверсу `king.exe` (декомпіляція Ghidra `re/decomp_king`, рядки, дизасемблер). Код не копіювався —
описано лише поведінку й розмітку. Графіка — `COMMON/esc16.RES` (16-біт) та `esc15.RES` (15-біт: ті самі імена з
`m15`/`m_15`, вибір за режимом відео). Вивантажено в `exports/ingame/ht2` (поза git). Огляд правил гри —
[Docs/ht2/gameplay.md](../../../Docs/ht2/gameplay.md).

Позначення: координати — у пікселях картинки-фону вікна (вікно для 1600×1200), «→» — кнопка з картинками
`<імʼя>_a/_p/_ap/_f` (звичайна, натиснута, під курсором, у фокусі); прапорці — ще `_pp`, `_n`/`_ok`.

## 1. Верхнє табло (весь час на екрані)
- **Обʼєкт** — конструктор 0x569760, малювання 0x569ab0.
- **Ресурси:**
  - рамка `m16\tablo.txr` (1600×50);
  - підписи — шрифт `matrix.fon` (7×13, кирилиця);
  - числа й значки — шрифт **`icon.fon`** (TGA 400×496, клітинки 25×31) — значки на табло не картинки, а символи
    цього шрифту;
  - звуки `pagerSound`, `emptytankSound`.
- **Залежність від роздільності:**

  | Ширина екрана | Рамка x | Початок даних | Пейджер |
  |---|---|---|---|
  | ≥ 1205 (1600) | 0 | 469 | (1161, 11) |
  | 801–1204 (1024) | −479 | −10 | (682, 11) |
  | 641–800 | −399 | 70 | (250, 50) |
  | 640 | −479 | −10 | (170, 50) |

- **Поля** — x від початку даних, y — базова лінія тексту. Перевірено макетом `exports/ingame/tablo_mock.png`, він
  збігається зі знімком з посібника (bm60).

| x | y | Що | Як |
|---|---|---|---|
| +26 | 23 / 43 | «ПОЗИЦИЯ» / місце | лише коли є суперники з тим самим замовленням; місце — дрібні цифри (код+0x10) |
| +50 (центр) / +63 | 38 / 43 | «из» / кількість | |
| +85 | 23 / 43 | «ОСТ.ВРЕМЯ» / мм:сс | лише з замовленням |
| +154, +210 / +158 | 23 / 43 | «ЛИЦЕНЗИЙ» N / час найгарячішої мм:сс | лише коли є ліцензії |
| ←287 | 38 | швидкість | великі цифри, вирівнювання праворуч |
| +291 | 40 | «км/ч» або «MpH» | |
| +315 | 40 | ручне гальмо — символи `[\` | блимає |
| +361 (+15 з автоматом) | 23 | «АКПП %c» / «КПП %c» | R, N або номер передачі |
| ←386 / +386 | 43 / 40 | оберти (цифра) / «x100 об/м» | |
| +458 | 40 | вантажівка без причепа `KL` / з причепом `MN` | блимає, поки зчіплюється |
| +512 | 40 | пальне: колонка `?` + стовпчик рівня 0x50+n | при ≤ 3 поділках блимає |
| +553 | 40 | стан машини: вантажівка `O` + стовпчик | інша піктограма `_` за певного стану машини — гіпотеза |
| +608 | 40 | **навігатор** | див. нижче |

- **Навігатор** має два режими:
  - є покращення «навигатор» (біт 0x2000 у стані гравця — гіпотеза за назвою): стрілка повороту на найближчій
    розвилці — ліворуч `;`, прямо `<`, праворуч `=`, порожньо `]`; стрілка блимає;
  - без нього — у мережевій гонці стрілка-компас на ціль у 8 напрямках, пари символів `` `a``, `bc`, `de`, `fg`,
    `hi`, `jk`, `lm`, `no`; в одиночній грі поле порожнє.
- **Блимання й звук.** Блимання (ручник, мало пального, стан машини, навігатор) вмикає спільний прапорець, і тоді
  грає сигнал.
- **`icon.fon`, ряди символів** (у шрифті є темний набір 0x30–0x6F і світлий 0xB0–0xEF; гра пише кодами 0x30–0x6F):
  - 0x30–0x3A — великі цифри та `:`;
  - 0x3B–0x3D — стрілки повороту; 0x3F — паливна колонка;
  - 0x40–0x4A — дрібні цифри;
  - 0x4B–0x4E — тягач і тягач з причепом; 0x4F — вантажівка (стан);
  - 0x50–0x5A — стовпчик рівня 0…10; 0x5B–0x5C — ручне гальмо; 0x5F — машина з ключем;
  - 0x60–0x6F — стрілки компаса.
- **Пейджер:**
  - `m16\pager_p.msk` (300×30) — стрічка; текст рядком шириною 247 пікселів, з відступом (34, 23);
  - `pager_a.msk` (21×19) — значок нового повідомлення, блимає в (+5, +6);
  - у черзі 4 повідомлення по 128 символів; однакові повідомлення поспіль відкидаються протягом кількох секунд.

## 2. Картки подій (праворуч, y = 50) — `m16\mess<N>.msk`
- **Хто показує:** обʼєкт повідомлень `MessTop` — рамка `m_16\MessTop.txr` 1600×50 (зверху) і `pause.msk` на паузі.
- **Виклик:** `eventBanner(xEventId, текст)` → тип 10, номер картки = xEventId. Картка стоїть притиснутою до правого
  краю екрана, поверх неї пишуться суми (шрифт `matrix`).

| N | Картка | Подія (де викликається) |
|---|---|---|
| 1 | «Ты лучший в заезде! Можешь открыть свою компанию!» + ліцензія | доставка першим, перша ліцензія (тип 5) |
| 2 | «Ты снова лучший в заезде!» | доставка першим, наступні ліцензії |
| 4 | «Заказ выполнен»: сохранность %, неустойка, гонорар, итого | звичайна доставка (тип 5, без ліцензії) |
| 6 | «Неустойка» | скасування замовлення |
| 7 | «Ваш груз полностью разбит. Неустойка» | вантаж знищено |
| 8 | «Время доставки истекло. Неустойка» | строк минув |
| 9 | «Штраф за нелегальный груз» | міліція, нелегальний вантаж |
| 10 | «Штраф за превышение скорости» (дві суми) | пост міліції |
| 11 | «Штраф за попытку дачи взятки» | невдалий хабар |
| 12 | «Штраф за проезд на красный свет» | світлофор |
| 13 | «Ваш грузовик числится в угоне. Возмещение ущерба» | крадена машина |
| 14 | «Вы виновны в ДТП. Нарушение: …» (текст порушення) | порушення ПДР з `Ms.sch` VIOLATION_* |
| 15 | «У вас проблемы с законом. Итого» | кілька штрафів разом |
| 16 | «Зарегистрировано превышение скорости. Ограничение / ваша скорость. Штраф» (220×230) | **радар** |
| 20 | «Вы ограблены бандитами» | мафія забрала гроші |
| 21 | «Бандитами отнят ваш груз» | мафія забрала вантаж |

- **Мафія: гроші чи вантаж** (0x445740 `mafiaAttack`). Гра порівнює суму вартості вантажів з числом у полі
  гравця +0xE0 (імовірно, «данина», яку вимагає мафія — гіпотеза):
  - вантаж дешевший або рівний — бандити забирають гроші (картка 20);
  - вантаж дорожчий — забирають сам вантаж (картка 21).
- **Інші типи повідомлень** — без картки, лише текст рядками по центру внизу.

## 3. Бічні панелі (F1–F4) і вікна біля обʼєктів
- **Розташування.** Фони — вузькі овали з `esc16.RES`. Усі малюються від точки бічної панелі (глобальні
  0x6ced0c/0x6ced10). Завантаження — у 0x56e5a0 (разом зі значками карти).
- **F1–F3** (0x5756f0):
  - F1 `BackF1` — таблиця клавіш у два стовпчики по 18 рядків (з `kmjin`);
  - F2 `BackF2` — рейтинг; `BackF2Tball` — те саме в мережевій грі;
  - F3 `BackF3` — «Инфо»; схема машини — `upgradet.txr` (вантажівка) або `upgradec.txr` (легковик), поверх неї
    значки встановленого `up_<система>_<0|1>.msk`.
  - F1: рядки клавіш — базова лінія 472 + 20·(n mod 18), стовпчики x 25 (дія) і 136 (клавіша), друга таблиця — на 170
    правіше. F3 (0x5756f0): опис замовлення (19, 492, ширина 148), премія (127, 552), два рядки 544/556 (x 20),
    гроші (23, 605), смуги 5 px: вага/обʼєм 628…636, шини/гальма 658…666, двигун/трансмісія 688…696 (ліва від x 17,
    права від x 96, довжина до 0x9e).
  - Схема F3 (0x574950): `upgradet` у (17, 722); значки `up_<назва>_1` (назви — таблиця 0x675c90: susp, vbrake,
    ebrake, shassis, glass, hlights, engine, oil, snorkel, tire, tire, ftank, abs, radar, stealth, scan, fire, navig,
    signal, transmiss, wheel; `…c` — легковик, 0x675ce4) у точках: susp (117, 809), vbrake (44, 791), ebrake
    (47, 792), shassis (27, 742), glass (28, 755), hlights (24, 786), engine (33, 809), oil (61, 809), snorkel
    (61, 734), шини (41/103/126, 786), ftank (71, 785), abs (117, 726), radar (21, 747), stealth (117, 754), scan
    (89, 754), fire (89, 809), navig (89, 726), signal (38, 737); `_0` — пошкоджене (двигун, гальма, шини, фари,
    трансмісія (34, 773), колесо (34, 763)), пороги — не розібрано.
- **F4** `BackMy` (0x526470) — «Моя компания»:
  - список водіїв зі скролом `mup/mdown/mrun`, фото `escphoto%02d` (з 54);
  - кнопки «поменяться местами» (186, 774) і «уволить» (85, 774).
- **Біля обʼєктів** — тип події визначає вікно (0x56bc80):

| Подія | Фон | Де |
|---|---|---|
| склад: замовлення (0x11), причіп / контейнер / цистерна (0x14, 0x19) | `BackOrder` «ЗАКАЗ» | склад |
| продаж машини (0x12) | `BackSale` «ПРОДАЁТСЯ» | стоянка |
| диспетчерська «Справка» (0x13) | `BackInfo` «ДИСПЕТЧЕРСКАЯ» | будка біля бази |
| водій шукає роботу (0x18) | `BackJob` «ИЩУ РАБОТУ» | стоянка |

- **СТО** — `BackService` (0x520e30, 640×1200, прикріплений до правого краю екрана):
  - **ремонт** (`check`, прапорці з `_ok`): 2 стовпчики по 4 рядки, x = 181 і 0, крок y = 19;
  - **модернізації** (`check`): 3 стовпчики 6 + 7 + 6, x = 362, 181, 0, крок 19;

  - Схема машини на F3 — ті самі `up_*_0/1.msk`, де `c` в імені (`up_glassc`) — варіант для легковика.
- **Заправка** — `BackGas` (0x520240, 225×1200):
  - повзунок рівня (25, 655), `gasfull` (175, 655);
  - `gaspay` (52, 755), `gascanc` (123, 755).

## 5. Меню «Проблемы в пути» (Esc) та інше
- **Esc** — `BackEscMain` (215×1200, 0x511170). Кнопки (0x50def0, команда) додаються списком від (18, 454) з кроком
  45 (0x5115b0(0x12, 0x1c6), 0x5be130(… + 0x2d)) у порядку `exitsys` 0xa9, `main` 0xa3, `sound` 0xa4, `control` 0xa5,
  **`911`** 0xa6, `restart` 0xa8, `loadg` 0x6e, `savg` 0xa7; на екрані — знизу вгору: згори `savg` (454), знизу
  `exitsys` (769) — перевірено збігом картинок кнопок із фоном у цих точках. У мережевій грі (поле гравця +0x524)
  restart, loadg і savg неактивні (`_f`).
- **Кнопки = фон + напис.** Поза написом картинка кнопки збігається з фоном панелі в точці кнопки (різниця ≈ 3 на
  канал), стани `_p/_a/_ap` відрізняються лише кольором напису: `_p` (140, 255, 173), `_a`/`_ap` (247, 255, 156),
  `_ap` — ще підкреслення. Великі літери — рядки 1…16 кнопки 150×30. Порт пише українські написи поверх
  (`ui/escLocale.ts`).
- **911** — тексти `mess.txt` 9 «ПЛАТА ЗА ВЫЗОВ $%d» і 125 «Восстановление через %d сек.»; обробник команди 0xa6
  статично не знайдено (вікно обробляє команди віртуальним методом) — відлік, місце й ціна в порту — гіпотези.
- **Підменю:**
  - `BackEscSnd` (0x516ea0) — повзунки (0x50d860, діапазон 0x8c) списком від (22, 489) з кроком 70: згори
    `voll/r` «общая громкость» (INI `sfxvol`), `musl/r` «музыка» (`midivol`), `engl/r` «звук двигателя» (`engvol`),
    `skidl/r` «звук торможения» (`skivol`); бігунок `runner`; доріжка намальована на фоні (x 41…143, рядки 501, 571,
    641, 711); кнопки `ok` 0xb8 (21, 762) і `canc` 2 (77, 762);
  - `BackEscCtrl` (0x517530) — від (22, 511): `sensl/r` «чувствительность руля» (`sens`), `centerl/r` «возврат руля»
    (`power`), `forcel/r` «обратная связь» (`force`); прапорець `agear` (0x50d1c0, 141, 700) — `autgb=on`; ті самі
    `ok`/`canc`;
  - `BackEscSave` / `BackEscLoad` — список імен, `nsave`, `delgame`, `mup/mdown`;
  - вихід — `excanc`, `exnsave`, `exsave`.
- **Кінцеві екрани** (0x51eea0, 1600×1200):
  - `BackLoose1` — знищено;
  - `BackLoose2` / `BackWin1` — програв / виграв гонку;
  - `BackLoose3` / `BackWin` / `BackWin2` — кінець гри;
  - `BackLoose4` — банкрут; `BackLoose5` — ще одна поразка (не переглянуто);
  - кнопки `o_main`, `o_rest`, `ow_main`, `ow_cont`, `ow_rest`.
- **Карта (Tab), значки** (0x529890):
  - `I_city0–3`, `I_fuel0–3` (стан або вибір), `I_gazhold`, `I_debris`, `I_repair`, `I_tank`, `I_race`, `I_box`,
    `I_park`, `I_trailer`;
  - свої водії — `I_tr_myNN_K` (24 машини × 6 станів), гравець `I_tr_myc`, суперник `I_tr_opp`;
  - прапорці `ic_flagr` / `ic_flagw` — гонка; логотипи компаній `icon1–8` (рейтинг F2, водії).
- **Дзеркала заднього виду** — рамки `mirr{L,R,T}{S,M,L,H}.msk`: ліве, праве, верхнє; S/M/L/H — гіпотеза:
  розмір за роздільністю.
- **Решта:**
  - підказки — `tip1_left/midd/right`;
  - курсор `cursor`, `cursor_a`;
  - завантаження — `loadpix`, `loadrunner`;
  - запис / повтор — `vtrpanel` + `vtr*`, цифри часу `big0–9`, `colon`;
  - підтвердження — `MenuPopupA5` з `5yes` / `5no`.
- **Код першої гри без ресурсів.** Імена `%s\small%d`, `gear%02d`, `rpm%02d`, `f_panel`, `m_panel`, `m_rul_%02d`,
  `fase_*` (2D-прилади першої гри) у даних другої відсутні — цей код лишився від HT1.
