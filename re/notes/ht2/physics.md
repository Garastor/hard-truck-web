## Сили й інтегрування (В1, 2026-10-16)
Джерела: `re/decomp_king` + `gq.py disasm` (x87-аргументи), константи прочитано з king.exe. Код не копійовано.
Позначки: **[код 0x…]** — підтверджено; **[гіпотеза]** — не доведено.

### Головне
Звичайна їзда — **не** динаміка твердого тіла з пружинами, а кінематична модель «велосипеда»: рух по дотичній до
ґрунту, швидкість щокадру примусово спрямовується вздовж курсу (бічного ковзання немає), поворот — кінематична
кутова швидкість v·sin δ/L, нахил кузова — за площиною контактів коліс плюс косметичний крен від прискорення.
Повна динаміка (пружини, демпфери, тензор інерції) — лише окремий «динамічний» режим після ударів/польоту.
**Виправлення 2026-10-18 (телеметрія, telemetry.md):** машина гравця без причепа весь час у режимі 3 —
динамічному (0x4f5820 + підкроки 0x4f8260, шини з кутом ковзання), а не в run1. Кінематичний run1 — для інших
машин/випадків; для порту гравця еталон — «Динамічний режим (0x4f8260)» нижче.

### Виправлення до якорів вище
- `[+0x19a4 + 2i]` (short) — **колесо в повітрі** (1 — нема контакту), не «ведуче» [код 0x4f0ce0, 0x505530,
  0x4fef20]. Ведуче — `[+0x1bb4 + 4i]` (`driving_wheels`) [код 0x4f3000, 0x4ff150].
- run2: колесо на землі — кут повороту за кадр = −(v_точки · напрям_кочення)/r · dt; у повітрі: ведуче з
  передачею (не нейтраль, 0x1c1c ≠ 1) — від обертів двигуна, інакше загасання ×0.9^(10·dt) [код 0x4f35f0,
  0x64c958 = 0.9, 0x64b780 = 10]; пробуксовка (стан ±1 у 0x19d4) — від обертів двигуна.
- `[+0x1c88]` — не головна передача, а **оберти макс. потужності n0** (`tach_with_max_power`, у tech множиться на
  1/60 → об/с) [код 0x508300: ×0x64c420 = 1/60; 0x4ff210, 0x507380 беруть 0x1c88 як n0].

### Режими кроку [код 0x4fef20, 0x4fc930]
`_Car_V::run` → 0x4feee0 → цикл 0x4fef20. Режим `[+0x2638]`: 0/1 — **звичайний** (0x4fdc80 `run1`, один крок на
кадр); 2/3 — **динамічний** (0x4f5820 / 0x4f8260; вмикає `_Vehicle::set_vehin_mode` 0x54ca60, викликаний з 0x55b590
разом з імпульсом 0x4f8130 — [гіпотеза] зіткнення/падіння), повертається в 0/1 через `form_position1` 0x4fb470.
**Уточнено 2026-10-17** — див. «Динамічний режим (0x4f8260)»: режим 2 не вживається, 0x4f8130 — не імпульс, вибір
1/3 — щокадру 0x548ec0 (або зчеплення з причепом).
`_Vehicle::make_new_Pos` (0x54a380) — обгортка: стан `_Vehicle` +0x2aac: 0 — балістика (x += v·dt, поворот на
|ω|·dt навколо осі ω), 5 — прикріплений до іншого обʼєкта, інакше — викликає віртуальний `_Car_V::run` і копіює
швидкість/позицію/оберти/передачу в `_Vehicle` (HUD, звук, мережа).

### Крок dt [код 0x4e2749]
dt = реальний час кадру, обмежений 0.25 с (0x64b738 / 0x64c334); у режимі фіксованого кроку — N/1000.
Підкроків немає (один `run1` на кадр).

### Порядок `run1` (0x4fdc80)
1. dt; `check_damage` 0x501930; **кермо** 0x500850 → **двигун/коробка** 0x4ff800.
2. Зберегти стан (0x4f0450); осі й контакти (0x4f0ce0 → 0x4f0800, 0x4f0530): n — нормаль ґрунту `[0xd0]`;
   курс f — вісь Y кузова `[0xa2c]`; f_t — f у площині ґрунту, нормований `[0xa38]`; v_t — швидкість у площині
   `[0x9f0]`, |v_t| `[0xdc4]`, **v_fwd = v_t·f_t** `[0xdc8]`; |v| `[0xdc0]`.
3. Кут керма δ = 0.7854·s (45° × положення керма s ∈ [−1, 1] `[0x29e0]`) [код 0x4f0090, 0x674408].
4. **Кінематичний поворот**: ω = ±|sin δ|/L·|v_fwd| (L — колісна база `[0x1f60]`; кут ковзання ЦМ
   β = atan(l_r/L·tg δ) рахує 0x4f0160); якщо обидва передні колеса в повітрі (0x19b5) — ω = 0. Вектор ω·n `[0xc24]`.
   Відцентрова сила F_c = ±M·|sin δ|/L·v² у напрямку (v̂ × n), повернута на δ `[0xc78]`. **У швидкість не додається** (виправлено 2026-10-18 за
   декомпіляцією 0x4fdc80): лише в «відчутне» прискорення g − (F + F_c)/M `[0xd58]` — крен кузова й кабіна.
5. `run2` (оберти коліс) і 0x4f3000 (поздовжні сили коліс, див. нижче).
6. Сума сил по колесах на землі: F = Σ [F_кочення_i (0xf08) + F_гальма_i (0x21b4) + F_тяги_i (0x2094),
   спроєктована на площину ⊥ нормалі контакту n_i] `[0xc6c]` [код 0x4fe339…0x4fe4d8, disasm]; зовнішні сили в
   точках (`[0x27c0]` штук, 0x27f8/0x2804 — [гіпотеза] причіп/зіткнення) → F_ext і момент.
7. Гравітація g = −9.8·up [код 0x4ee540, 0x64d990]; **якщо всі колеса на землі — дотична складова g ×0.5**
   (схили «вдвічі пологіші» для розгону/скочування) [код 0x4fdc80, 0x64c258 = 0.5].
8. **Швидкість**: v += (g_eff + F/(M + M_прич) + F_ext/M)·dt (F_c — ні); M_прич = `[0x278c]` (маса причепа,
   0x558850) [код].
9. Не в повітрі: v → дотична до ґрунту; далі, якщо n_z ≥ 0.8 (схил < ~37°, 0x64b898) і жодна пара коліс не в
   повітрі: **v := sign(v·f_t)·|v|·f_t** — швидкість повністю вздовж курсу [код 0x4fe82f…0x4fe912].
10. Орієнтація: поворот навколо осі Z кузова на ω·dt; якщо передні колеса в повітрі — вільне обертання з
    кутовими швидкостями [0x58..0x60] (= момент імпульсу [0x4c] / діагональ інерції [0x1f48]).
11. Позиція += v·dt.
12. 0x505530 — **пошук контактів** для нової матриці; 0x4fca10 — **вирівнювання кузова** за контактами (результат
    замінює матрицю); обернена матриця [0x900]. Перекидання (0x4f0000): up·Z_кузова < 0.17 або |Z_кузова.y| > 0.94
    → `[0x3344]` = 1.

### Контакти й навантаження коліс (0x505530)
- Повний промінь до дороги (0x503e30) — лише для 2 передніх за ходом коліс (заднім ходом — 2 задніх); решта
  проєктуються на площину найближчого «провідного» колеса.
- Хід c_i = z_маточини − r_i − z_контакту (у системі кузова) `[0xe18+4i]`; c < 0 або > хід `[0x1f9c+4i]` → новий
  промінь; нема контакту → c = 1000, колесо в повітрі, N = 0.
- **N_i = M·9.8/n_коліс·|n_i,z|** `[0xd20+4i]` [код, 0x64d6b8 = 9.8] — рівний розподіл, не від пружин.
- μ_avg — середнє μ коліс на землі `[0x26b0]`; нормаль ґрунту — середня нормаль контактів; центр контактів `[0x2214]`.

### Поздовжні сили коліс (0x4f3000) — «коло тертя» по одному напрямку
Колесо на землі: F_max = μ_i·N_i (μ `[0x2670]`); S = 0.01 + Σ F_max ведучих.
- тяга F_d = F_max·T_drive/S (T_drive `[0x1c94]` — сила від двигуна, розподіл пропорційно зчепленню);
- гальмо F_b = B_i·b (знак — за напрямом руху), b `[0x29dc]` діє при b > 0.1; B_i = **1.5 × статичне
  навантаження колеса** `[0x1c98]` [код 0x4ee540, 0x64b668 = 1.5] (`breakpower` у цьому шляху не знайдено);
- нетто = F_d − F_b: |нетто| ≤ F_max — сила нетто вздовж напряму кочення (як тяга або гальмо);
- інакше: тяга переважає → **пробуксовка** (сила = F_max, прапорець 0x19c4, стан +1); гальмо переважає →
  **блокування** (при |v| > 1 м/с; стан −1, кут колеса не змінюється), сила = −min(1, k)·F_max проти руху.
Бічної сили шини немає (бічний рух знято кроком 9).

### Опір кочення (0x503500) і поверхні (0x502780)
- μ за замовчуванням 0.5 (дощ/сніг, `DAT_0069784c == 1` — 0.3); за типом поверхні — таблиця
  μ[поверхня + (погода + шини·2)·14] (0x6976f8, .bss — **звідки заповнюється, не знайдено**).
- Коеф. кочення f_r = 0.01 за замовч. `[0x2690]`; R = f_r·N·φ(v_колеса), φ(v) = (v+6)·v/((v+c)·(2v+6))·k
  (0x507330; φ(0) = 0); для бездоріжжя (типи 2, 4/7/9, 6/10/11) — інші формули і **випадкова нерівність** висоти
  колеса (random walk у 0xe3c, межі ±0.1…0.3 м). Проколена шина — додатковий опір.

### Кермо (0x500850)
- Клавіші: s змінюється зі швидкістю ∝ (час утримання + 0.2)·20·чутливість `[0x2724]`·dt/(0.25·|v| + 1) (×2 у
  режимі 0x2701, інакше ×0.66); |s| ≤ 1; повернення до центру ×p^(10·dt), p = 0.99·(1 − σ) + 0.01
  (σ — налаштування `[0x2728]`; σ < 0.05 — не повертається, > 0.95 — p = 0.1).
- **Обмеження керма гравця**: |s| ≤ min(1, 1.5·atan(μ_avg·k·L/v²)) (k `[0x263c]`) при |v| ≥ 0.1 — не дає
  повернути більше, ніж дозволяє зчеплення.

### Двигун і коробка (0x4ff800 і помічники)
- Газ `[0x29d8]`, гальмо `[0x29dc]` з клавіш: (t + 0.001)/(t + 1) (t — час утримання) або (t + 0.001)/(t + 0.1).
- **Крива моменту** (0x507380), n — оберти (об/с), n0 = `tach_with_max_power`/60: n ← max(n, 0.1·n0);
  T(n) = (A/B)·exp(−(|n − n0|/n0)^4); при n < n0 ще ×√sin(π/2·n/n0)·(n/n0)^0.2.
  A, B — системи техстану (0x3ebc, 0x3fc0 через 0x4eb5e0; [гіпотеза] `maxrotmomentum` з покращеннями/пошкодж.).
- **Гальмування двигуном** (0x507360): T_br(n) = −n·c_f − n·E·√b (c_f `[0x1c8c]`; у tech поруч обчислюється
  0.2·maxrotmomentum/(2·n0) — [гіпотеза] це c_f; E — система 0x3ff4).
- Разом: T = g·T(n) + (1 − g)·T_br(n), g ∈ [0, 1] (0x507440). **Сила тяги** F = T·i_g·rear_axle_coeff/rwheel
  (0x507490: tech 0x697938 + 4·g, 0x697934, 0x6978cc) → згладжування в часі (`filterEngineAccel`) → `[0x1c94]`.
- **Оберти від коліс** (0x4ff150): n = v_fwd/r_сер·i_g/(2π), не менше 0.05·n0; нейтраль/усі ведучі в повітрі —
  n = 3·g·n0; при n < 0.5·n0 — змішування з 2·g·n0 (зчеплення, 0x4ff210); згладжування `filterEngineTach`
  (0x4eacce/0x4eaf98 — зважене середнє за вікном часу).
- Передачі: 0 — задня (`reverse_trans_coeff`), 1 — нейтраль, 2… — `gear_trans_coeff%d` (відсутня = попередня ×

- **Промені коліс** (0x503e30; викликають 0x504d30, 0x505530 з кімнатою 0): кімната колеса — кімната машини
  (`+0x1a10`) або ціль порталу, який перетинає відрізок центр машини → (колесо + 1 м угору) (0x5039a0); якщо цей
  відрізок у щось влучив — колесо без контакту [К]. Промінь — уздовж осі Z кузова, від колеса ± L, L = n²·(dt·√|v| +
  r_i) + 1 (n = 1…3 спроби) [К]. Запит режиму 4: або весь вузол кімнати (vtable+0x34), або (`+0x2708` ≠ 0)
