# Перемикачі моделей вантажівок HT2 (TRUCKS.B3D) — стоп-сигнали, задній хід, побиті колеса, вмʼятини

[К] — підтверджено кодом king.exe (адреса), [Д] — дані, [Г] — гіпотеза.

## Звідки беруться вказівники [К 0x53fdb0]
Завантаження моделей (0x53fdb0), на модель — запис `0x5d0` байт від `0x6d20f0`:
- вузли `%sBFaraL` / `%sBFaraR` (0x679a04 / 0x679988) → `StopFaraKeyL` (+0x6d211c), `BackFaraKeyL` (+0x6d212c),
  `StopFaraKeyR` (+0x6d2120), `BackFaraKeyR` (+0x6d2130); BFara шукаються для всіх категорій (і причепів), FFara —
  лише не для категорій 3/4 (SEMI_TRAILERS/TRAILERS з vehicle.tech, поле `0x6981ac`, 0x508300).
- `DamageWheel%dKey` (0x679948) для i = 0…(кількість коліс моделі `0x6980cc`)−1 → `+0x6d215c + 4i` (поруч `%swheel%d`).
- `FGLKey`, `FGRKey`, `BGLKey`, `BGRKey` → `+0x6d218c…` (світіння габаритів).

## Стоп-сигнали й задній хід [К 0x546d10, викликає 0x547030 — оновлення моделі за кадр]
[Д] Групи перемикачів: `StopFaraKeyX` — 3 групи: 0 порожня (вимкнено), 1 `StopLight1R_0` (стоп), 2 `TailLight1R_0`
(габарит); `BackFaraKeyX` — 0 порожня, 1 `BackLight1R_0`.
Поля машини (база 0x546d10): `+0x5178` — гальмо (стоп), `+0x517c` — задній хід, `+0x51b4` — габарити,
`+0x51b8` — фари 0/1/2, біт `0x80` у `+0x51a4` — «пошкодження ввімкнено» (ставить 0x5427a0 після створення зон).
Зони вмʼятин: Z6 = BR, Z7 = BL (стани в `[+0x2540]+0x7c/+0x90`).
- `StopFaraKeyL` = `StopFaraKeyR` = 1, якщо гальмо і не (пошкодж. && Z6 ≠ 0); інакше 2, якщо габарити; інакше 0.
  Стоп **замінює** габарит (одночасно не горять). Пошкоджений ліхтар не дає стопу, але габарит лишається.
- `BackFaraKeyL` = 1, якщо задній хід і не (пошкодж. && Z7 ≠ 0); `BackFaraKeyR` — те саме з Z6.
- Код спершу ставить StopL за Z7 (0/1), а потім перезаписує за Z6 — ймовірно, помилка оригіналу; фактично обидва
  стопи залежать від Z6 (BR).
- Світіння `FGL/FGR/BGL/BGRKey` = габарити; `+0x5014` (фари) — увімкнено, якщо `+0x51b8` ≠ 0 або габарити.
- Габарити `+0x51b4` щокадру переписує 0x54ff80 (0x550562): година гри (double `[0x6f33ac]+0x58`, усічена) у 5…22 →
  0, інакше 1.
- Звідки береться `+0x5178`/`+0x517c` для локальної машини — **не знайдено**: єдиний запис у коді — розпаковка
  стану 0x54d690 (біти 5 і 6 слова `+0x27b4`; запаковує назад 0x54ff80). Те, що це педаль гальма / задня
  передача, — [Г] за назвами. Тягач → причіп (0x558990) копіює `+0x517c` і `+0x51b4`, **але не** `+0x5178`.

## Підсистеми машини (фізичний обʼєкт `[+0x5460]`, масив від `+0x3c9c`, крок 0x14) [К]
Запис: `+4` стан (int), `+8` макс., `+0xc` мін., `+0x10` частка (float), `+0x14` швидкість накопичення.
Індекси (0x5017a0 / 0x501810 / 0x501870 / 0x501b90): 0 двигун (макс 3), 1 коробка (макс 2), 2 кермо (±3),
**3+i — шина колеса i** (макс **3**, швидкість 0,05; 0x4ebd00), 11+i — ±2 (читачів не знайдено),
19+i — гальмо колеса i (макс 1; ≠ 0 → сила гальма ×0,2, 0x501930).
Накопичення (0x500ef0): частка += шкода·швидкість (≤ 1), стан = trunc(макс·частка).

## Побиті колеса `DamageWheel<N>Key` [К]
- N — номер колеса у фізиці (порядок `wheel_space0…` з TCH; у порту FL, FR, BL, BR, далі додаткові). [Д] 4 групи
  (стани 0…3). Стан у модель — копія шини `[0x5460]+0x3cdc+0x14i` → `+0x5280+4i` (кінець 0x548250) → перемикач
  (0x547030).
- Причини:
  1. **Удар** поруч із колесом (0x501010, з колізії 0x554c20): d² = |точка_колеса − точка_удару|² < 5 м² →
     шкода (E − 1)·0,5/(d² + 0,5)·k_напряму у шину, «±»-запис 11+i і гальмо 19+i колеса (0x500ef0). E — енергія
     удару (формула в 0x554c20, нижче).
  2. **Шипи/покриття 13** (0x503500, case 0xd): колесо отримує таймер; за 2 с (0x674444) частка шини лінійно
     росте до 1 (0x4f5820 → 0x5017a0) → стан 3 (спущене). Звʼязок покриття 13 з `PinKey` мафії — [Г].
  3. Заплановані поломки (0x4eb420 → 0x4ebbe0, тип 0): випадкове колесо 0 або 1 (передні) +1, лише поки стан <
     макс−1. Хто планує — не встановлено.
- Фізика (0x501930 `_Car_V::check_damage`): робочий радіус `[0x1b74+4i]`: стан 0 — R `[0x1d60+4i]`; стан = макс —
  Rд `[0x1d80+4i]` (радіус диска [Г]); стан 1 — 0,75R + 0,25(Rд + (R−Rд)·f); стан 2 — 0,5(R + Rд + (R−Rд)·f),
  f = таблиця синуса (кут колеса + π/2 + π) — колесо «биться» з обертом.
  Додатковий опір кочення (0x503500): (стан/макс)·N·v·5/(v + 5) проти руху. Показник справності 0x501550
  (min 1 − k·стан/макс, k 0,9 / 0,6 / 0,3) → 0x557000 — використання не знайдено.
- Ремонт: сервіс 0x555c80 (шини, ціна колеса `+0x28f0+4i`, кошторис 0x555d10), 0x555b70 (записи 11+i, 19+i),
  0x555f30 (усе); часткова сплата — 0x501e30 (на крок). Зберігаються в кар'єрі/мережі (0x546300, 0x546240: 9 зон +
  8 коліс).

## Вмʼятини `Damage<1|FC|FR|FL|R|L|BR|BL|BC>Key` [К 0x5465c0, 0x554c20, 0x5553e0]
- Зони (0x5465c0): 0 «1», 1 FC, 2 FR, 3 FL, 4 R, 5 L, 6 BR, 7 BL, 8 BC; макс. станів 4,3,3,3,1,1,3,3,1; швидкість
  0,1 (FC 0,05). Перемикач `Damage%sKey` шукається в моделі машини. Стан = trunc(макс·частка), частка += a·швидкість
  (0x589450, через 0x591660).
- Колізія (0x554c20, лише якщо біт 0x80): v = |імпульс|/маса; v < 2 — без шкоди; v' = v − 2,
  E = v'·(1 + 15v'/(v' + 5))·(1 − 0,96·exp(−(0,04(v' − 10))²)). Точка удару → локальні координати, n — нормований
  вектор до неї (x — праворуч, y — вперед). Удар зверху (z > |x| і z > |y|) — без шкоди. Далі:
  - ny > 0: a = ny²·E (×0,2 із захистом фар) → зони 1, 2, 3;
  - s = 0,7071(nx + ny) > 0 → зона 2 (FR) s²·E (×0,2); s = 0,7071(ny − nx) > 0 → зона 3 (FL) s²·E (×0,2);
  - −ny > 0 → зона 8 (BC) ny²·E;
  - 0,5nx − 0,866ny > 0 → зона 6 (BR) (…)²·E; −0,866ny − 0,5nx > 0 → зона 7 (BL) (…)²·E;
  - nx > 0 → зона 4 (R) **nx·E** (лінійно); −nx > 0 → зона 5 (L) −nx·E.
- Зона 0 (`Damage1Key`, 5 станів) не б'ється напряму — 0x5553e0 виводить її з передніх: FR ≥ 2 і FL ≥ 2 → 4;
  FR ≥ 1 і FL ≥ 1 → 3; FR ≥ 1 і Z0 ≤ 2 → 2; FL ≥ 1 і Z0 ≤ 2 → 1; FC ≥ 1 → 3; інакше 0.
- Обʼєкти трафіку (0x52d350…0x52d530) теж мають зони; їхній удар/постріл (0x52bd20) — лише зони 1–3.
- Причіп: обʼєкти напівпричепів — того самого великого класу (0x547030 має гілку для діапазону SEMI_TRAILERS), тож
  та сама логіка зон [Г: створення причепа не простежено]. [Д] У STrailerP/T/M перемикачів `Damage*Key` немає; у
  STrailerStorm — лише `refer_DamageBC/L/RKey`, у кузовах `LNKTRL0_*` — `refer_DamageL/R/BCKey`; `*BackLights` причепа
  мають `DamageBCKey`.
