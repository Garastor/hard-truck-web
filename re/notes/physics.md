# Фізика вантажівки (R4) — стан дослідження

Мета: відтворити формули `_Car_V` (двигун, КПП, сили шин, підвіска, інтегратор), щоб порт поводився як оригінал.
Зараз у порту — **тимчасова** модель (`web/src/game/truckVehicle.ts`).

## Якорі в HTruck.exe

| Адреса | Що | Звідки відомо |
|--------|----|---------------|
| `0x49f22c` | `_Car_V::run2` — головний крок симуляції машини (≈2700 рядків псевдо-C) | рядок `_Car_V:run2` |
| `0x49eaa0` | `_Car_V::get_WheelsForces` — сили на колесах | рядок |
| `0x4b0070` | `_Car_V::check_damage` | рядок |
| `0x4bcd68` | `VEHICLE::RUN` (після `make_new_Pos`, `Move`) — інтегрування руху | рядки |
| `0x491558` | нормалізація кутів у [−π, π] (константи ±π, ±2π, ±1000) | константи |
| `0x483f48` | читання `[TECHn]` (див. `tech-params.md`) | рядки ключів |
| `0x4966dc` | створення машини: копіює запис техніки (`0x59d7dc + i·0x540`) в обʼєкт | `* 0x540` |
| `0x4872b8` | звуки машини: `idleSound` (+0x20), `fullSound` (+0x24), `gearSound` (+0x28), `extcarSound` (+0x30) … | рядки |
| `0x48a008` | HUD: маски `gear%02d`, `gear_r`, `rpm%02d`, `autogear` | рядки |

Константи в `run2`: −π/2, 0.01, 1e-4, 0.5, 2, 6, 1e-3, 5, 0.05, 0.1, 4, 3, 10, 0.3, 0.6, 0.15643 (≈ sin 9°), 2.5.
Константи в `get_WheelsForces`: 3, 1e-3, 5, 10, 2.5. Поле обʼєкта `+0x4a8` — схоже на поздовжню швидкість,
`+0x95c` — момент на ведучих колесах, `+0x8dc[i]` — ознака ведучого колеса, `+0x710[i]` — колесо відірване.

## Що відомо з get_WheelsForces (попередньо)
- Момент на ведучих колесах ділиться пропорційно навантаженню (`+0x41c[i] · +0xc2c[i]`) між ведучими колесами.
- Якщо частка моменту перевищує межу зчеплення — колесо буксує (прапорець `+0x728[i]`), сила обрізається.
- Опір кочення ∝ −|v| з коефіцієнтом `3 · (+0x948) / (+0x950) / r`.

## План (наступна сесія, бажано разом з тобою)
1. **Динаміка через Cheat Engine** (вже встановлено): запустити оригінал через dgVoodoo2, знайти в памʼяті швидкість
   (спідометр) → «Find what writes» → адреса в `run2`/`RUN`; так само оберти й передачу. Це дасть точні зсуви полів.
2. З відомими полями перейменувати змінні в Ghidra (`gq.py rename`, або MCP) і переписати формули псевдокодом тут.
3. Телеметрія (Frida або Cheat Engine Lua): розгін 0–60/0–100 км/год на кожній передачі, гальмівний шлях з 60,
   радіус розвороту — для кожної вантажівки. Збережемо в `re/telemetry/*.csv` → автотест порту (допуск ±5 %).
4. Замінити тимчасову модель на відтворену.
