# Фізика вантажівки (R4) — стан дослідження

Мета: відтворити формули `_Car_V` (двигун, КПП, сили шин, підвіска, інтегратор), щоб порт поводився як оригінал.
Зараз у порту — **тимчасова** модель (`web/src/game/truckVehicle.ts`).

`+0x95c` — момент на ведучих колесах, `+0x8dc[i]` — ознака ведучого колеса, `+0x710[i]` — колесо відірване.

## Що відомо з get_WheelsForces (попередньо)
- Момент на ведучих колесах ділиться пропорційно навантаженню (`+0x41c[i] · +0xc2c[i]`) між ведучими колесами.
- Якщо частка моменту перевищує межу зчеплення — колесо буксує (прапорець `+0x728[i]`), сила обрізається.
- Опір кочення ∝ −|v| з коефіцієнтом `3 · (+0x948) / (+0x950) / r`.

## План (наступна сесія, бажано разом з тобою)
1. **Динаміка через Cheat Engine** (вже встановлено): запустити оригінал через dgVoodoo2, знайти в памʼяті швидкість
   (спідометр) → «Find what writes» → адреса в `run2`/`RUN`; так само оберти й передачу. Це дасть точні зсуви полів.
2. З відомими полями перейменувати змінні в Ghidra (`gq.py rename`, або MCP) і переписати формули псевдокодом тут.
3. Телеметрія (Frida або Cheat Engine Lua): розгін 0–60/0–100 км/год на кожній передачі, гальмівний шлях з 60,
   радіус розвороту — для кожної вантажівки. Збережемо в `re/telemetry/*.csv` → автотест порту (допуск ±5 %).
4. Замінити тимчасову модель на відтворену.

## Двигун і коробка — відтворено (2026-10-10, статика + телеметрія)

Джерела: `0x4aa76c` (крок двигуна/КПП), `0x4aa388` (крива моменту), `0x4aa320` (гальмування двигуном),
`0x4aa46c`, `0x4aa4f4`, `0x4aa514`, `0x4aa5d4`, `0x4aa1c0`; створення машини `0x4966dc`.
Телеметрія: `tools/re/telemetry.py` (читання памʼяті запущеної гри), запис `re/telemetry/s6.*` (ЗіЛ, база, 33 с).
Обʼєкт машини знаходимо за полями [0x251] = rear_axle_coeff і [0x253] = maxrotmomentum (вони незмінні).

### Формули
- Момент двигуна (`0x4aa388`), n — оберти (об/с), n ≥ 0,1·n₀:
  `T(n) = M · exp(−(|n − n₀| / (1,5·n₀))⁴)`, а при n < n₀ ще `× sin(π/2 · n/n₀) × (n/n₀)^0,2`.
- Гальмування двигуном (`0x4aa320`): `Tb(n) = −0,1·M/n₀ · n`.
- Сумарний (`0x4aa46c`): `Te = g·T(n) + (1 − g)·Tb(n)`, g — газ [0, 1].
- Сила на колесах (`0x4aa4f4`): `F = Te · ratio[передача] / rwheel`; після перемикання протягом 1 с
  плавно переходить від попередньої і обмежена `0,9 · Σ (навантаження · тертя)` ведучих коліс (`0x4aa514`).
- Газ із клавіатури: `g = t / (t + 1,2)`, t — час утримання (с); мінімум 0,05 на нейтралі, 0,001 на передачі.
- Автомат: для вищих передач рахує силу тяги при відповідних обертах; вгору — якщо сила > поточна × 1,1;
  вниз — якщо на нижчій передачі вигідніше із запасом 0,5. Під час перемикання — нейтраль, оберти лінійно
  переходять від [0x256] до n₀ за 0,3 с (автомат); після — n = 2·газ·n₀.
- На нейтралі оберти тягнуться до 0,5·n₀·… з коефіцієнтом газу.
- Перевірка: 3-тя передача, 5 с газу → модель 9535·0,806 = 7690 Н, гра — 7713 Н (0,3 %).


## Гальма й опір руху (2026-10-10, телеметрія s6/s7 + `get_WheelsForces` 0x49eaa0)
- Гальмо з клавіатури [0x33a] наростає як `t / (t + 1)` (0,11 → 0,20 → … → 0,65 за 2 с).
- Гальмівна сила колеса [0x258 + i] (раніше помилково — «вартість машини»): ЗіЛ — передні 17 714 Н
  (0,49·breakpower), задні 12 421 Н (0,35·breakpower); зменшується під час кожного гальмування (знос гальм).
  Сила колеса = гальмо × [0x258 + i], обмежена тертям × навантаження × [0x1e7 + i] (зчеплення колеса).
- Тертя колеса [0x30b + i] = 0,84 (= friction_coeff 1,4 з truck.ini × 0,6?) — гіпотеза.
- Тяга ведучих коліс ділиться пропорційно навантаженню; межа — навантаження × тертя, інакше буксування (+0x728).
- Опір руху: накат на 3-й без газу з 8,4 м/с — 0,44 м/с² = гальмування двигуном (≈ 1320 Н) + кочення ≈ 0,015·m·g.
- Порт (truckVehicle.ts): гальмування 8,1 → 0,5 м/с за 1,40 с (оригінал ≈ 1,38 с), накат 0,46 м/с² (0,44).
- Ще не розібрано: бічні сили шин, підвіска (ks/cs/hmin/hmax), інтегрування кузова — у `run2` (x87-код зіпсований
  декомпілятором; потрібна ручна розмітка дизасемблера).


## Кермо й зчеплення в повороті (2026-10-10, телеметрія s6)
- Кермо з клавіатури [0x230] (вліво) / [0x22f] (вправо): при утриманні — плавно (S-крива) від 0 до межі
  за ≈ 1,1 с; відпущено — експоненційно до нуля (≈ 4,3 1/с). Межа залежить від швидкості:
  `1,04 / (1 + 0,056·v)`, не більше 0,913 (0,91 на 2,5 м/с, 0,84 на 4,3, 0,79 на 6, 0,70 на 8,5).
- Кут колеса [0x1d9]/[0x1dc] = 0,684 × кермо (до ≈ 39°); внутрішнє більше — `cot o − cot i = 0,208` (Аккерман).
- Коло з кермом до упору: R ≈ 8 м на 3,5 м/с, ≈ 17,8 м на 7,5 м/с — сильна недостатня повертаність
  (бокове прискорення ≈ 0,33 g при гальмуванні до 0,55 g).
- Порт: кермо — точно за формулами; зчеплення — калібрування Rapier `frictionSlip = 0,42`
  (під час гальмування плавно до 1,0): R = 7,4 / 17,4 м. Справжня модель бічних сил шин — у `run2`, не розібрано.

- Уточнення (відгук користувача «менше ковзала, бадьоріше розганялась»): спільна межа зчеплення 0,42 різала тягу
  задніх ведучих коліс (≈ 8 кН замість 14 кН). Тепер 0,42 — лише передні (недоповорот), задні — 0,84 (тертя оригіналу).
- Ривок на старті: після включення передачі з нейтралі газ [0x339] = 1,0 протягом ≈ 0,27 с (s6: 23,54–23,68 с),
  далі — звичайне наростання t/(t + 1,2).
- Розгін з місця (порт / оригінал, с від натискання газу): 2,35 м/с — 0,72 / 1,14; 4,0 — 1,92 / 1,81;
  7,05 — 3,92 / 3,56; 8,4 — 4,83 / 5,05.
