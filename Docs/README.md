# Hard Truck Web — порт «Дальнобійників» (1998) у браузер

**Мета:** відтворити оригінальну гру *Hard Truck / Дальнобойщики* (SoftLab-NSK, 1998) у браузері,
з орієнтацією насамперед на мобільні пристрої (сенсорне керування, PWA, офлайн).

**Підхід:** не емуляція `HTruck.exe`, а **реімплементація рушія** на TypeScript + WebGL,
яка читає/конвертує *оригінальні ресурси гри* (B3D, RMP, TXR, MSK, PLM, TCH, OVL).
Уся реалізація ведеться за допомогою **Claude Code**.

## Структура проєкту

```
Hard Truck/
├── CLAUDE.md            ← інструкції для Claude Code (контекст проєкту)
├── Docs/                ← цей план
├── Game/Hard Truck/     ← оригінальна гра (НЕ комітити в git!)
├── re/                  ← проєкт Ghidra (не комітити) + re/notes/*.md (висновки реверсу)
├── tools/               ← Python/Node утиліти: дослідження та конвертація ресурсів
│   ├── probe/           ← скрипти-зонди форматів
│   └── re/              ← запити до Ghidra (gq.py), налаштування Watcom
└── web/                 ← сам веб-порт (Vite + TypeScript + Three.js + Rapier)
```
