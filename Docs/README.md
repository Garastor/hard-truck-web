# Hard Truck Web — порт «Дальнобійників» 1 і 2 у браузер

**Мета:** відтворити оригінальні ігри *Hard Truck / Дальнобойщики* (SoftLab-NSK, 1998) і
*Дальнобойщики 2* (2001) у браузері, з орієнтацією насамперед на мобільні пристрої (сенсорне керування, PWA, офлайн).

**Пограти:** https://garastor.github.io/hard-truck-web/ — на сайті лише код порту; файли гри кожен імпортує свої
(тека або ZIP оригіналу, див. [play-on-phone.md](play-on-phone.md)).

**Підхід:** не емуляція `HTruck.exe` / `king.exe`, а **реімплементація рушія** на TypeScript + Three.js + Rapier,
яка читає *оригінальні ресурси гри* (B3D, RES/RMP, TXR, MSK, PLM, TCH, OVL; у другій грі ще WAY, tech, `*.sch`).
У кожної гри — свій рушій; спільна лише оболонка запуску (вибір гри, імпорт файлів, PWA).
Уся реалізація ведеться за допомогою **Claude Code**.

## Структура проєкту

```
Hard Truck/
├── CLAUDE.md              ← інструкції для Claude Code (контекст проєкту)
├── .github/workflows/     ← CI: тести, збірка й розгортання на GitHub Pages
├── Docs/                  ← документи: спільні, ht1/, ht2/
├── Game/                  ← оригінальні ігри (НЕ комітити в git!)
├── re/                    ← проєкти Ghidra (не комітити) + re/notes/ht1|ht2/*.md (висновки реверсу)
├── tools/                 ← Python утиліти
│   ├── probe/             ← скрипти-зонди форматів
│   ├── re/                ← Ghidra (gq.py), телеметрія: procmem.py (спільне), ht1/, ht2/
│   └── refactor/          ← перенесення модулів і документів
└── web/                   ← веб-порт (Vite + TypeScript + Three.js + Rapier)
    ├── src/shared/        ← контракт запуску (GameModule, сховище файлів)
    ├── src/app/           ← оболонка: вибір гри, імпорт файлів, PWA
    ├── src/games/ht1/     ← перша гра (свій рушій — engine/)
    ├── src/games/ht2/     ← друга гра (свій рушій — engine/)
    └── test/              ← ht1/, ht2/, architecture.test.ts
```
