# Журнал прогресу

## 2026-10-10 (ніч, автономна робота Claude Code)

### Реверс `HTruck.exe` (доріжка R)
- **R0 ✅** Проєкт Ghidra `re/htruck` + власний компілятор-специфікація **Watcom** (`__watcall`), бо в Ghidra її немає
  (`tools/re/install_watcom_cspec.py`). Підтверджено на дизасемблері: аргументи в EAX, EDX, EBX, ECX, далі стек.
- CLI `tools/re/gq.py` — запити до Ghidra з терміналу (рядки, декомпіляція, перехресні посилання, перейменування,
  vtable, експорт усього коду). Уся програма (2334 функції) декомпільована в `re/decomp/` (локально, не в git).
- `.mcp.json` — сервер `pyghidra-mcp` для наступних сесій Claude Code (після перезапуску).
- **R2 ✅** Завантажувач B3D: фабрика блоків `0x43c170`, методи читання класів (vtable+0x2c), «форми» тригерів
  `0x44ad24`. Результат — повний формат у [formats/b3d.md](formats/b3d.md).
- **R3 ✅** Параметри техніки `[TECHn]` (ключі, значення за замовчуванням, структура запису) — `re/notes/tech-params.md`.

### Формати (Фаза 1) — усе читається до останнього байта
- RMP/RES (13 архівів), TXR (8 і 16 біт), MSK (4 варіанти, 5721 маска), PLM, B3D (12 сцен), TCH/INI.
- Відкриття: кожна локація має **два набори** — `*.B3D`+`*.RMP` (програмний рендер, 8 біт) і
  `*2.B3D`+`*3.RMP` (3D-прискорювач, 16-бітні текстури, більше деталей). Порт використовує другий.
- 26 golden-тестів на реальних файлах (`web/test/formats.test.ts`), `npm test`.

### Рендер (Фаза 2)
- Переглядач `web/`: усі 6 локацій з оригінальними текстурами, галерея текстур і масок, моделі вантажівок.
- Система координат гри: X праворуч, Y уперед, Z угору (права) — перевірено за позиціями фар/водія в TCH.

### Їзда (Фази 3–4, перша версія)
- Фізика Rapier (raycast-vehicle): маса, радіус коліс, передачі, головна передача, момент — з `TRUCK.TCH`.
  Автоматична КПП, задній хід утриманням гальма, 3 камери (C), скидання (R).
- Старт на найближчій до `Observer` лінії дороги `way_*`.
- Сенсорне керування (◀ ▶ ГАЛЬМО ГАЗ 👁 ↺), компактний інтерфейс у режимі їзди, геймпад.
- Rapier вантажиться лише в режимі їзди: стартовий бандл 145 КБ gzip.

### Як подивитися
```bash
npm run dev --prefix web
```
Відкрити http://localhost:5173 (або `http://<IP-ПК>:5173` з телефону в тій самій Wi-Fi мережі).
Вкладки: Сцена · Текстури · Маски · Техніка · Їзда. Клавіатура: стрілки/WASD, пробіл — ручник, C — камера, R — скидання.

### Відомі обмеження / наступні кроки
- Формули двигуна й КПП — тимчасові; замінити відтвореними з `_Car_V::run2` (R4).
- Немає неба (купол), спрайтів (тип 28: фари, дерева-білборди), анімованих матеріалів, звуку.
- Колізії — по візуальній геометрії; перейти на колізійні блоки 23.
- Перемикачі (LOD/пошкодження/світлофори) — завжди група 0.
