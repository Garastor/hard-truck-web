# 08. Розширення рушія «Клим»: Дальнобойщики 2 (King of the Road)

Стан: **план** (2026-10-12). Позначки як у [../ht1/roadmap.md](../ht1/roadmap.md): `[x]` / `[~]` / `[ ]`.
Гра: GOG-версія *Hard Truck 2: King of the Road* (`king.exe`, MSVC 6, збірка 2004-01-14, DirectDraw/D3D7),
локально — `D:\Games\Hard Truck 2` (**лише читати**, як і `Game/`).

## 1. Рішення

- **Один рушій, кілька ігор.** HT2 — той самий рушій SoftLab пізнішої версії; наші парсери вже читають майже всі
  його ресурси (§2). Окремий рушій не пишемо; спільне ядро виділяємо поступово, а не великим рефакторингом наперед.
- **Профіль гри** (`GameProfile`) визначає файли, сховище, меню, режими й збереження. HT1 лишається як є —
  без повторного імпорту й без втрати кар'єр.
- **Меню вибору гри** — лише коли на пристрої (або на dev-сервері) повних ігор більше однієї (§5).
- Правила проєкту ті самі: параметри з файлів гри, ефекти — з механізмів оригіналу, код з `king.exe` не копіюємо.

## 4. Архітектура

### 4.1 Профіль гри
```ts
type GameId = 'ht1' | 'ht2';
interface GameProfile {
  id: GameId;
  title: string;                  // «Дальнобойщики», «Дальнобойщики 2»
  required: string[];             // канонічні шляхи для імпорту (лише потрібне на телефоні)
  detect(paths: string[]): boolean; // за вмістом теки/zip: HTruck.exe+TRUCK.TCH | king.exe+ENV/aa.b3d
  source(): FileSource;           // dev: /game/ | /game2/; пристрій: IndexedDB з префіксом
  run(ctx: AppContext): Promise<void>; // меню й режими гри
}
```
### 4.2 Розкладка коду
З 2026-10-16 ігри розділені повністю (Docs/09-structure-plan.md): у другої гри свій рушій `games/ht2/engine/` (копія,
далі розвивається окремо — власна фізика з king.exe), формати лише HT2 — `games/ht2/formats/`; спільні з першою грою
лише `shared/` (контракт запуску, сховище файлів) і оболонка `app/`.

### 4.3 Сховище, URL, збереження
- IndexedDB `hard-truck-files`: ключі HT1 **не змінюються**; HT2 — з префіксом `ht2/` (одна БД, одна квота,
  `storageInfo` рахує по іграх).
- Dev-сервер: `/game/` → HT1 (як зараз), `/game2/` → тека HT2 (за замовчуванням `Game/Hard Truck 2` —
  junction на `D:\Games\Hard Truck 2`; або змінна `HT2_DIR`). Плюс `/games.json` — які ігри доступні.
- Golden-тести HT2 — з `skipIf`, як HT1.
- localStorage: HT1 — без змін (`ht.careers.v1`, `ht.control`…); HT2 — `ht2.*`; спільні налаштування керування
  й якості — спільні; останній вибір гри — `ht.game`.
- URL налагодження: `?game=ht2&tab=…`; без `game` — HT1 (старі посилання працюють).

## 5. Меню вибору гри

**Коли показується:** при запуску, якщо повних ігор ≥ 2. Одна — одразу її головне меню (як зараз). Нуль — екран
імпорту, який сам визначає гру за вмістом теки/zip.

**Вигляд** (спільний для обох ігор, бо зʼявляється раніше за будь-яке меню гри):
- Каркас `Screen` 640×480 з масштабуванням під телефон (ландшафт), поля, великі цілі для пальця.
- Дві «картки» гри: зменшений фон головного меню з її `LOAD.RES` (HT1 — `m/back_mai`; HT2 — фон/лого з його
  `LOAD.RES`, підібрати) + назва піксельним шрифтом `MENU.FON` (`pixelFont`, `softUi`). Стани кнопки —
  як у `maskButton` (під пальцем / натиснута / вибрана); остання вибрана гра підсвічена.
- Заголовок «Рушій «Клим»» і рядок присвяти — як у головному меню HT1.
- Під картками — «Додати гру» (імпорт) і «Опції» (спільні налаштування, сховище по іграх, видалення файлів гри).
- Без графіки (немає `LOAD.RES`) — простий HTML-варіант, як у наявних запасних діалогах.

**Пряме посилання на гру** (GitHub Pages — статичний хостинг, тож це справжні теки зі своїм `index.html`):
`…/hard-truck-web/` — вибір гри; `…/ht1/` — одразу «Дальнобойщики»; `…/ht2/` — одразу «Дальнобойщики 2».
Кожна тека має свій `manifest.webmanifest` (назва, `start_url`) — на iPhone дві окремі іконки на домашньому екрані.
Файли й збереження спільні (один домен). `?game=ht2` — запасний варіант для налагодження.

**Повернення:** кнопка «Выход/Вихід» головного меню гри (зараз неактивна для гравця) веде до вибору гри, коли ігор
≥ 2; у dev — як і раніше, до переглядача за налагоджувальним посиланням.

| Ризик | Що робимо |
|-------|-----------|
| Памʼять/нагрів iPhone у відкритому світі | Бюджет з G3, полегшені `*1/*2.res`, вибіркові вантажівки за OVL, режими якості |

| Ліцензійна чистота | Не копіювати `ht2-rev` (без ліцензії) і D2GI (GPL); MIT-джерела — з атрибуцією в коді/доках |
