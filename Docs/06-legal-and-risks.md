# 06. Авторські права та ризики

> Це не юридична консультація — лише практичні рамки для проєкту.

## 1. Що кому належить

- Гра *Hard Truck / Дальнобойщики* (1998), її ресурси (моделі, текстури, звуки, відео, музика) та `HTruck.exe` —
  обʼєкти авторського права правовласників (SoftLab-NSK / видавці). Те, що гра «стара», не робить її вільною.
- **Наш код рушія** — наш. Специфікації форматів спільноти — під MIT (можна використовувати з атрибуцією).

## 2. Модель розповсюдження (як у OpenMW, OpenRCT2, ScummVM)

| Що | Де | Можна публікувати? |
|----|----|--------------------|
| Код рушія, конвертерів, документація | GitHub (приватний → за бажанням публічний) | ✅ так |
| Ресурси гри (оригінальні або конвертовані) | Лише на пристрої гравця (OPFS) або на вашому приватному хостингу для особистого використання | ❌ ні, публічно — ні |
| `HTruck.exe`, дизасембльований код | Ніде | ❌ ні |

Тому в архітектурі закладено **імпорт файлів гри користувачем** (Фаза 7): веб-сайт віддає лише код,
а гравець указує свою копію гри — конвертація відбувається локально в браузері.

Для особистої гри на своєму телефоні допустимий спрощений варіант: зібрати ресурси локально
і роздавати з ПК у домашній мережі / з приватного хостингу з паролем.

## 3. Музика

У наявних файлах музики немає (була CD-Audio). Варіанти:
1. Рип власного CD (аудіодоріжки є лише на фізичному диску або в образі `.cue/.bin`; у скопійованій папці `Hard_Truck_CD1` їх немає) → гравець імпортує треки разом з рештою файлів (як ресурси).
2. Вільна музика (CC0/CC-BY) у стилі «дорожнього року» як замінник.
3. Підтримка «своєї» музики гравця (вибрати файли/плейлист).

Рекомендація: 3 + 1 (дати гравцю підкласти будь-які аудіофайли, зокрема рип CD).

## 4. Реверс-інжиніринг

- Розбір **форматів даних** для сумісності — звичайна практика (і вже зроблено спільнотою).
- Аналіз `HTruck.exe` у Ghidra — лише для розуміння поведінки; **не копіювати** дизасембльований код у проєкт,
  реалізовувати поведінку власним кодом.
