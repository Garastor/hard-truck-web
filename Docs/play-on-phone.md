# Як пограти на телефоні

## Варіант А — через ПК у домашній мережі (найпростіше, для розробки)

1. На ПК запустити dev-сервер:
   ```bash
   npm run dev --prefix web
   ```
2. Дізнатися IP-адресу ПК у мережі:
   ```bash
   ipconfig
   ```
   (рядок «IPv4 Address», напр. `192.168.1.23`).
3. На телефоні (та сама Wi-Fi мережа) відкрити `http://192.168.1.23:5173/?tab=drive`.
   Файли гри телефон бере з ПК, нічого імпортувати не треба.
   Якщо не відкривається — дозволити Node.js у брандмауері Windows для приватних мереж.

## Варіант Б — гра повністю на телефоні (офлайн, PWA)

1. Зібрати порт:
   ```bash
   npm run build --prefix web
   ```
2. Розмістити теку `web/dist` на **HTTPS**-хостингу статичних файлів. Там лише код порту — без файлів гри
   (див. [06-legal-and-risks.md](06-legal-and-risks.md)). Обрано **GitHub Pages** з публічного репозиторію:
   `.github/workflows/deploy.yml` на кожен `git push` у `main` перевіряє типи, проганяє тести (тести на файлах
   гри без них пропускаються), збирає й викладає `web/dist` на `https://<логін>.github.io/<репозиторій>/`
   (≈ 1–2 хв). Адреса гри: **https://garastor.github.io/hard-truck-web/** (репозиторій
   https://github.com/Garastor/hard-truck-web). Сторінка закрита від пошукових систем
   (`noindex`). Пункт 1 тоді робить GitHub.
3. На телефоні відкрити адресу (з інтернетом — один раз). Код гри кешується одразу весь.
4. **Спершу встановити:** Safari → «Поділитися» → «На початковий екран» (Android: меню браузера → «Встановити» /
   «Додати на головний екран»). На iPhone застосунок з головного екрана має **окреме сховище** від Safari:
   файли, імпортовані в Safari, він не побачить — тому імпорт робити вже в ньому (гра про це підкаже).
5. Запустити гру з іконки, натиснути «Обрати ZIP» і вибрати свій `HardTruck.zip` (або «Обрати теку гри»).
   Потрібні ≈ 66 МБ розпакуються в памʼять пристрою (IndexedDB) один раз. Далі — офлайн, на весь екран.

**Дві гри.** Порт запускає й «Дальнобойщики 2» (файли гри ≈ 150 МБ: архів чи тека GOG-версії; гру впізнає сам).
Якщо на пристрої обидві — на старті екран вибору гри, «Вихід» у головному меню повертає до нього. Пряма адреса
кожної гри: **…/hard-truck-web/ht1/** і **…/hard-truck-web/ht2/** — встановлена з такої адреси іконка одразу
відкриває свою гру (на iPhone — дві окремі іконки; файли й збереження спільні).

**Оновлення.** Коли на хостингу нова збірка, а телефон в інтернеті, гра завантажує її у фоні й показує
«Є нова версія гри» → «Оновити» (або «Пізніше» — до наступного запуску). Файли гри при цьому не чіпаються.

**Стан файлів** — «Опції»: «Файли гри» (чи всі на пристрої й скільки місця зайнято; тап — імпортувати знову) і
«Сховище» («захищене» — браузер не очистить дані сам; «браузер може очистити» — у Safari без встановлення на
головний екран дані сайту стираються, якщо його ~7 днів не відкривати).

> Без HTTPS (напр. `http://192.168…:4173` з `npm run preview -- --host`) імпорт працює, але офлайн-режим і
> встановлення як застосунку — ні: браузери дозволяють service worker лише на HTTPS або localhost.

## Керування

| Дія | Телефон | Клавіатура | Геймпад |
|-----|---------|-----------|---------|
| Кермо | ◀ ▶ | ← → / A D | лівий стік |
| Газ / гальмо (утримання гальма на місці — задній хід) | ГАЗ / ГАЛЬМО | ↑ ↓ / W S | R2 / L2 |
| Камера (кабіна → позаду → здалеку) | 👁 | C | — |
| Рестарт на точці сектора | ↺ | R | — |
| Клаксон | ріжок угорі | H | — |
| Ручник | — | Пробіл | — |
| Автопілот (тест) | — | P | — |

Керування нахилом телефона, обмін місцями керма й педалей, якість графіки — у меню ☰ → ⚙ «Опції».
Табло гравця (праворуч над педалями) згортається тапом.

Меню ☰: «Кар'єра / Тест» (тест — вибір траси, вантажівки й погоди, мінікарта завжди).
Параметри адреси: `?level=CIRCUIT|COUNT|MOUNT|NIGHT|TRIAL|MENU3D`, `&truck=1..9`, `&ai=0..7`, `&tab=drive`, `&career=1`.
