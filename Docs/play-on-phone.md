# Як пограти на телефоні

## Варіант А — через ПК у домашній мережі (найпростіше, для розробки)

1. На ПК запустити dev-сервер:
   ```bash
   npm run dev --prefix web
   ```
2. Дізнатися IP-адресу ПК у мережі:
   ```bash
   ipconfig
   ```
   (рядок «IPv4 Address», напр. `192.168.1.23`).
3. На телефоні (та сама Wi-Fi мережа) відкрити `http://192.168.1.23:5173/?tab=drive`.
   Файли гри телефон бере з ПК, нічого імпортувати не треба.
   Якщо не відкривається — дозволити Node.js у брандмауері Windows для приватних мереж.

## Варіант Б — гра повністю на телефоні (офлайн, PWA)

1. Зібрати порт:
   ```bash
   npm run build --prefix web
   ```
2. Розмістити теку `web/dist` на **HTTPS**-хостингу статичних файлів. Там лише код порту — без файлів гри
   (див. [06-legal-and-risks.md](06-legal-and-risks.md)). Обрано **GitHub Pages** з публічного репозиторію:
   `.github/workflows/deploy.yml` на кожен `git push` у `main` перевіряє типи, проганяє тести (тести на файлах
   гри без них пропускаються), збирає й викладає `web/dist` на `https://<логін>.github.io/<репозиторій>/`
   (≈ 1–2 хв). Адреса гри: **https://garastor.github.io/hard-truck-web/** (репозиторій
   https://github.com/Garastor/hard-truck-web). Сторінка закрита від пошукових систем
   (`noindex`). Пункт 1 тоді робить GitHub.
3. На телефоні відкрити адресу (з інтернетом — один раз). Код гри кешується одразу весь.
4. **Спершу встановити:** Safari → «Поділитися» → «На початковий екран» (Android: меню браузера → «Встановити» /
   «Додати на головний екран»). На iPhone застосунок з головного екрана має **окреме сховище** від Safari:
   файли, імпортовані в Safari, він не побачить — тому імпорт робити вже в ньому (гра про це підкаже).
5. Запустити гру з іконки, натиснути «Обрати ZIP» і вибрати свій `HardTruck.zip` (або «Обрати теку гри»).
   Потрібні ≈ 66 МБ розпакуються в памʼять пристрою (IndexedDB) один раз. Далі — офлайн, на весь екран.

**Дві гри.** Порт запускає й «Дальнобойщики 2» (файли гри ≈ 150 МБ: архів чи тека GOG-версії; гру впізнає сам).
Якщо на пристрої обидві — на старті екран вибору гри, «Вихід» у головному меню повертає до нього. Пряма адреса
кожної гри: **…/hard-truck-web/ht1/** і **…/hard-truck-web/ht2/** — встановлена з такої адреси іконка одразу
відкриває свою гру (на iPhone — дві окремі іконки; файли й збереження спільні).

**Оновлення.** Коли на хостингу нова збірка, а телефон в інтернеті, гра завантажує її у фоні й показує
«Є нова версія гри» → «Оновити» (або «Пізніше» — до наступного запуску). Файли гри при цьому не чіпаються.

**Стан файлів** — «Опції»: «Файли гри» (чи всі на пристрої й скільки місця зайнято; тап — імпортувати знову) і
«Сховище» («захищене» — браузер не очистить дані сам; «браузер може очистити» — у Safari без встановлення на
головний екран дані сайту стираються, якщо його ~7 днів не відкривати).

**Книжковий режим на iPhone (застосунок з головного екрана).** Після повороту в портрет iOS віддає «вікно»,
коротше за екран на висоту рядка стану (`innerHeight` 797 замість 844). Екран вибору гри (`web/src/app/select.ts`,
`select.css`) тому тягнеться на `100lvh` у режимі standalone, міряє себе (не `window.inner*`) і вписує сцену в
безпечну зону (`env(safe-area-inset-*)`), інакше заголовок ховався під «бровку», а знизу лишалася сіра смуга.

**Бік «бровки» в ландшафті.** Браузер не каже прямо, з якого боку виріз (Dynamic Island, отвір камери).
`web/src/app/platform/notch.ts` визначає його так: бічні безпечні відступи різні — бровка з більшого боку;
однакові й ненульові (iOS у ландшафті робить їх симетричними) — за поворотом екрана (`window.orientation`
90 → бровка ліворуч, −90 → праворуч; без нього — `screen.orientation.angle` 90/270); нульові — бік невідомий.
Результат — `data-notch="left|right"` на `<html>`, оновлюється при повороті й зміні розміру (повторно через
300 мс: iOS оновлює відступи із запізненням).
- CSS (`style.css`): `--sal`/`--sar` — безпечна зона зліва/справа, з боку без бровки — 0; `--sl`/`--sr` —
  відступ інтерфейсу (меню, табло, верхні кнопки, панелі HT2). Телефон у ландшафті: 52 px (або безпечна зона +
  12) з обох боків, коли бік невідомий, і **20 px** з боку без бровки, коли відомий.
- **Кнопки руху** (кермо, газ, гальмо, «Різко») беруть окремі `--cl`/`--cr` — симетричні, як раніше, на бровку
  не реагують (на прохання користувача). Нове правило для них — лише через `--cl`/`--cr`.
- Де крутити: запас з боку без бровки — `:root[data-notch=…] { --sr/--sl: 20px }` у `style.css`.
- Перевірка: у мобільному вʼюпорті безпечних відступів немає (бік невідомий) — поставити
  `document.documentElement.dataset.notch = 'left'` і порівняти `getBoundingClientRect()` кнопки 👁 (до краю 20 px)
  і педалей (52 px, без змін). Правильність самого визначення — лише на телефоні.

> Без HTTPS (напр. `http://192.168…:4173` з `npm run preview -- --host`) імпорт працює, але офлайн-режим і
> встановлення як застосунку — ні: браузери дозволяють service worker лише на HTTPS або localhost.

## Керування

| Дія | Телефон | Клавіатура | Геймпад |
|-----|---------|-----------|---------|
| Кермо | ◀ ▶ | ← → / A D | лівий стік |
| Газ / гальмо (утримання гальма на місці — задній хід) | ГАЗ / ГАЛЬМО | ↑ ↓ / W S | R2 / L2 |
| Камера (кабіна → позаду → здалеку) | 👁 | C | — |
| Рестарт на точці сектора | ↺ | R | — |
| Клаксон | ріжок угорі | H | — |
| Ручник | — | Пробіл | — |
| Автопілот (тест) | — | P | — |

Керування нахилом телефона, обмін місцями керма й педалей, якість графіки — у меню ☰ → ⚙ «Опції».

**Дальнобойщики 2: частота кадрів і роздільність** — головне меню → «Графика». Стрілки в рядку над роздільністю
(де в оригіналі вибір відеокарти): «30 FPS» / «40 FPS» / «60 FPS». Менше — менше роботи й нагріву, рух трохи менш
плавний (40 — рівно на екранах 120 Гц; на 60 Гц кадри по черзі через 2 і 1 оновлення). Роздільність на телефоні —
стільки ж пікселів, скільки в назві (640×480 = 307 тис.): на iPhone у ландшафті ≈ 815×377 / 1019×471 / 1305×603 /
2038×942; на ПК — висота кадру (640×480 → 480 рядків). Без вибору світиться та, що діє (на iPhone — «1024×768»,
≈ 1266×585). Обидва — з наступного заїзду; фізика однакова за будь-якої частоти.

**Дальнобойщики 2: «різко» (Ctrl) з телефона** (`games/ht2/engine/input/input.ts`, `sharpGesture`). Окремої
кнопки немає: натиснувши кнопку керма, зсуньте палець у бік повороту на третину ширини кнопки (назад — вимкнути).
Кнопку газу так само зсуньте **вгору** на третину висоти: газ без антибукса, як Ctrl+газ в оригіналі, і колеса
можна зірвати (звичайний газ обмежено межею зчеплення). На iPhone з 3D Touch діє ще й сильне натискання. Поки
«різко» увімкнене, кнопка мерехтить. Кермо й педалі HT2 лежать поверх бічних панелей, карти й табло (`ht2.css`,
z-index 35). Під ними лишаються тільки вікно результату й повноекранні відео. Тож машиною можна керувати й тоді,
коли вікно відкрите.
Табло гравця (праворуч над педалями) згортається тапом.

Меню ☰: «Кар'єра / Тест» (тест — вибір траси, вантажівки й погоди, мінікарта завжди).
Параметри адреси: `?level=CIRCUIT|COUNT|MOUNT|NIGHT|TRIAL|MENU3D`, `&truck=1..9`, `&ai=0..7`, `&tab=drive`, `&career=1`.

**Дальнобойщики 2: панелі ліворуч.** Кермо й педалі зазвичай поверх вікон гри (можна їхати з відкритою картою чи
рацією). Коли відкрита панель ліворуч (F1–F4, меню Esc), кнопки з лівого боку екрана (кермо, а з «педалями ліворуч» —
педалі) йдуть під неї й не реагують на дотик; праві лишаються зверху (`body.ht2-left-open`, `ht2.css`).
Коли відкрите вікно станції праворуч (закупівля, сервіс, заправка, замовлення), праві кнопки (педалі, а з «педалями
ліворуч» — кермо) плавно відсуваються ліворуч на ширину панелі й повертаються після закриття: `SidePanel` з
`side: 'right'` (`ui/panel.ts`) ставить `body.ht2-right-open` і `--ht2-right-panel-w`, зсув — `translate` у `ht2.css`.
Якщо панель широка (СТО: 640 з 812 px ландшафту iPhone) і відсунута пара налізла б на ліву (`rightPairCramped`,
проміжок < 8 px), праві кнопки стають другим рядом над лівими — сітка 2×2 біля лівого краю (`body.ht2-right-stack`):
гальмо над «ліворуч», газ над «праворуч» (з «педалями ліворуч» — навпаки).
Сама панель СТО на екрані, нижчому за 500 px, — на 10% менша й зсунута донизу: низ кнопок OK/скасування (рядок
фону 825) — за 4 px від низу екрана, інакше верх (вантажівка, ремонт) ховався під табло (`SidePanel`, параметр
`compactBottom`; числа — `COMPACT_*` у `ui/panel.ts`).

**Дальнобойщики 2: камера по колу.** Група «•••» із зовнішньою камерою має 4-й ряд «камера ліворуч / праворуч»
(тримати — камера за машиною обходить її, 60°/с); з кабіни цього ряду немає. Ракурс скидає кнопка камери.
