# 04. План робіт (Roadmap)

Кожна фаза завершується **демонстрованим результатом** у браузері (крім Фази 0–1).
Задачі сформульовані так, щоб їх можна було віддавати Claude Code як окремі сесії (див. [05](05-claude-code-workflow.md)).
Оцінки — орієнтовні, у «сесіях» Claude Code (≈1 сесія = 1–3 год. спільної роботи).

> **Паралельна доріжка R (реверс `HTruck.exe`)** описана в [07-reverse-engineering.md](07-reverse-engineering.md#4-план-реверсу-паралельна-доріжка-r).
> Звʼязки: R2 → Фаза 1–2 (блоки B3D), R3–R5 → Фаза 3 (фізика), R6 → Фаза 5 (логіка), R7 → Фази 4/6.

---

## Фаза 0 — Середовище та каркас (1–2 сесії)

- [ ] Встановити Node.js LTS, gh CLI, ImHex; запустити оригінал через dgVoodoo2
- [ ] `git init`, `.gitignore` (виключити `Game/`, `build/assets/`, `*.zip`, `*.avi`), приватний репозиторій GitHub
- [ ] Створити `web/` (Vite + TypeScript + Three.js), ESLint/Prettier, Vitest, Playwright
- [ ] `tools/` — Node-пакет для CLI-конвертерів (спільний код з `web/src/formats`)
- [ ] `.claude/launch.json` для dev-сервера (превʼю у вбудованому браузері Claude Code)
- [ ] Порожня сцена з обертанням куба на телефоні в ландшафті (перевірка повноекранного режиму)
- [ ] Записати еталонне відео/скріншоти оригіналу: меню, кожна локація, вид з кабіни, HUD

**Готово, коли:** `npm run dev` відкривається на телефоні в локальній мережі; тести запускаються.

## Фаза 1 — Розбір форматів (3–5 сесій)

- [ ] Підключити `.ksy` з reRNR/RNRFileFormats, згенерувати TS-парсери; де не підходять для HT1 — дописати власні
- [ ] `rmp`/`res` — розпакування в папку (CLI `tools/unpack`), golden-тест на всіх 13 архівах
- [ ] `plm` — палітри; `txr` — TGA type 1 + 16-біт (LOFF/PFRM/LVMP) → PNG
- [ ] `msk` — декодер масок → PNG (HUD, прилади, дощ)
- [ ] `b3d` — повний обхід дерева блоків для всіх 12 файлів; невідомі типи — лог + сирий дамп
- [ ] `tch`, `ovl`, `truck.ini` — парсери тексту → JSON
- [ ] Debug-сторінка «Asset Browser»: список текстур/масок/звуків/матеріалів, дерево B3D

**Готово, коли:** усі файли гри розбираються до останнього байта; Asset Browser показує всі текстури.

## Фаза 2 — Рендер статичної сцени (3–4 сесії)

- [ ] Геометрія блоків 6/7 + полігони 8/28/35 → `BufferGeometry`; трансформи 24; інстанси 4/18
- [ ] Матеріали з RMP: `tex`, `ttx` (alpha), `col`, `transp`, `env`/`reflect`, `rot`/`move` (анімовані)
- [ ] Небо (`BACKFILES`, `SkyDomeKey`), туман з `truck.ini`, сонце/лінзи
- [ ] Вільна камера, перегляд кожної локації; LOD (блок 10), перемикачі (21, маркер 444)
- [ ] Кімнати (19) + портали (30) → відсікання невидимого
- [ ] Офлайн-конвертер у glTF + атласи (для швидкого завантаження), порівняння з еталонними скріншотами

**Готово, коли:** можна «прольотіти» камерою по CIRCUIT на телефоні з ≥30 FPS і впізнати оригінал.

## Фаза 3 — Вантажівка та фізика (4–6 сесій)

- [ ] Моделі вантажівок з B3D (вузли з `TRUCK.TCH`): кузов, колеса, фари, стоп-сигнали, двірники
- [ ] Колізійна геометрія світу (20, 23, дорога) → Rapier trimesh/heightfield
- [ ] Raycast-vehicle: підвіска, зчеплення (`friction_coeff`), кермо (`steering_sence`), КПП, двигун з TCH
- [ ] Камери: позаду, з кабіни (`cockpit_space`, огляд головою), зверху
- [ ] Звук двигуна (пітч від обертів), перемикання передач, гальма, удари
- [ ] Реалізувати формули з `re/notes/physics.md` (R4), параметри з TCH
- [ ] Debug-панель тюнінгу фізики (lil-gui)
- [ ] Автотест: наша фізика vs еталонна телеметрія оригіналу (R5/R8), допуск ±5 %

**Готово, коли:** можна проїхати повне коло CIRCUIT на ЗіЛ-і з клавіатури, відчуття — «як в оригіналі».

## Фаза 4 — Мобільне керування та HUD (2–3 сесії)

- [ ] Абстракція вводу; сенсорні пресети (кнопки / повзунок-кермо / нахил), геймпад
- [ ] HUD з MSK: тахометр і спідометр (`TachScale`, `SpeedScale`), панель кабіни (`panel_mask`), дзеркала/монітор
- [ ] Повноекранний режим, блокування орієнтації, Wake Lock, пауза при згортанні
- [ ] Адаптивна якість (pixelRatio, дальність, тіні) за FPS
- [ ] Тести на реальних пристроях (Android + iPhone), Playwright-скріншоти в мобільних профілях

**Готово, коли:** у гру комфортно грати на телефоні 10+ хвилин без перегріву і просідань <30 FPS.

## Фаза 5 — Ігрова логіка (5–8 сесій)

- [ ] Вивчити правила оригіналу (`HTruck.hlp`, гра в оригінал, `DEMO.TR`) → документ `Docs/gameplay.md`
- [ ] Події з B3D: старт/фініш/рестарт (13), тригери (9), дощ у тунелях, світлофори (21)
- [ ] ШІ-суперники по лініях `way_*` (20) з обгоном/уникненням зіткнень (`aicar=3`)
- [ ] Режими гри та прогрес гравця (профіль як `ВОДИТЕЛЬ.pl`), вибір вантажівки, гроші/рейтинг — як в оригіналі
- [ ] Пошкодження, вибухи (`explosion`, `hitAnmObj*`), рестарт
- [ ] Погода/ніч (локація NIGHT, `RainKey`), фари
- [ ] Збереження прогресу в IndexedDB
- [ ] (За потреби) Ghidra-аналіз `HTruck.exe` для точних формул

**Готово, коли:** можна пройти повний ігровий цикл на всіх 5 локаціях.

## Фаза 6 — Меню, звук, відео, локалізація (2–3 сесії)

- [ ] 3D-меню на базі `MENU3D` + інтерфейс з `LOAD.RES` (адаптований під сенсор)
- [ ] Шрифти з `MENU.FON`/`large.fon` (растрові → bitmap-font) або сучасний шрифт у стилі
- [ ] Інтро-відео (`HTruck.avi` → MP4), пропуск тапом
- [ ] Музика (див. рішення в [06](06-legal-and-risks.md)); мікшер гучностей як у `truck.ini [EFFECTS]`
- [ ] Локалізація: українська, російська (оригінал), англійська

## Фаза 7 — PWA, імпорт ресурсів, реліз (2–3 сесії)

- [ ] Екран першого запуску: «Оберіть файли гри» (zip/папка) → конвертація у Worker → OPFS, прогрес
- [ ] Service Worker: офлайн-гра, оновлення коду без повторного імпорту ресурсів
- [ ] Маніфест PWA, іконки, splash; Lighthouse ≥ 90 (PWA/Performance)
- [ ] CI (GitHub Actions): lint, тести, збірка; деплой коду (без ресурсів)
- [ ] (Опційно) Capacitor-обгортка для Android APK

## Фаза 8 — Покращення (backlog, після паритету з оригіналом)

- Покращена графіка (опційно): тіні, згладжування, білінійна фільтрація замість «піксельної»
- Мультиплеєр (оригінал мав DirectPlay) — WebRTC/WebSocket
- Перемикач «оригінальна / покращена фізика»
- Підтримка ресурсів *Дальнобійників 2* (формати близькі)

## Ризики, що можуть зсунути план

| Ризик | Ймовірність | Що робимо |
|-------|------------|-----------|
| Невідомі блоки B3D у HT1 | Висока | Ранній Asset Browser, звірка з оригіналом, ImHex; Фаза 1 — з запасом |
| Фізика «не та» | Середня | Реверс формул (доріжка R), еталонна телеметрія, автотести відхилень |
| Watcom ускладнює декомпіляцію | Середня | Налаштувати `__watcall`, перевіряти гіпотези в x32dbg |
| Продуктивність на слабких телефонах | Середня | Портальне відсікання, атласи, KTX2, динамічна роздільність |
| Немає музики | Висока | Див. [06](06-legal-and-risks.md) |
| Правові обмеження | Середня | Ресурси лише від гравця, код — окремо |
