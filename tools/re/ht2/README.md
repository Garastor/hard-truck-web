# tools/re/ht2 — телеметрія king.exe (Дальнобойщики 2)

Лише **читання** памʼяті запущеної гри (`D:\Games\Hard Truck 2\king.exe`), нічого не пише в процес.
Спільний доступ до памʼяті (`Proc`, `find_pid`) — з `tools/re/telemetry.py` (першої гри); решта — тут.
Висновки — `re/notes/ht2-telemetry.md`; записи — `re/telemetry/ht2/` (не комітити).
Скіл: `.claude/skills/ht2-telemetry`.

| Файл | Призначення |
|------|-------------|
| `record.py` | **Основний записувач**: чекає гру, знаходить машину гравця за міткою класу (0x00531aa0 на +0x8c), CSV 10 Гц (швидкість, оберти, передача, газ, кермо, паливо, одометр…) |
| `stopgo.py` | Пошук обʼєкта машини за профілем «стоїть → розгін → гальмування» (якщо мітка перестане працювати) + запис вікон |
| `recwin.py` | Запис вікон ±0x1000 навколо заданих адрес (поки гра не перезапущена) |
| `regionanalyze.py`, `winanalyze.py` | Аналіз записаних вікон: позиція, швидкість з позиції, кореляція полів |
| `velscan.py` | Кореляція всіх float у сторінках, що змінюються, зі швидкістю рухомих обʼєктів |
| `snapscan.py` | Порівняння знімків памʼяті (режим `auto` — чекає гру) |
| `techtable.py` | Таблиця техніки: копії записів `vehicle.tech` у памʼяті (`find`, `dump`, `record`) |
| `slicescan.py`, `carscan.py`, `ptrscan.py` | Пошук фрагментів запису tech, машин за масою/колесом, вказівників |

```bash
.venv/Scripts/python -I tools/re/ht2/record.py re/telemetry/ht2/drive 10
```
